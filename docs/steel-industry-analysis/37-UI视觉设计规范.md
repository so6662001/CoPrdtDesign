# UI 视觉设计规范

> 本文是 28-33 号 PRD 中 UI 草图的视觉级规范。设计师按本文做 Figma/Sketch 高保真稿，前端工程师按本文做 UI 组件库。
>
> 适用读者：UI/UX 设计师、前端工程师、产品经理。
>
> **本文不画真正的设计稿**（Figma 是设计师工作），是给设计师/前端做高保真 UI 时的"风格圣经"和"组件库定义"。

---

## 一、设计哲学

### 1.1 三大核心原则

| 原则 | 说明 |
|---|---|
| **真实**（Authentic） | 拒绝浮夸/玻璃拟态/3D 立体，钢贸老板看着累。用真实数据/真实场景/真实图片。 |
| **直接**（Direct） | 一屏一个核心任务，3 步以内完成；不要"先注册 → 引导 → 教程"，进来就能用。 |
| **专业**（Professional） | 不要花哨配色/可爱图标，钢贸是严肃 B2B；用克制的色彩、清晰的字体。 |

### 1.2 用户特征（决定设计风格）

```
钢贸老板典型画像:
  - 年龄: 35-55 岁
  - 性别: 80% 男性
  - 设备: 安卓为主（华为/OPPO/vivo），iPhone 占比上升
  - 屏幕尺寸: 6.1-6.7 寸（中端机居多）
  - 视力: 部分需要老花镜
  - 网络: 4G/5G 混合，WiFi 在办公室
  - 操作习惯: 单手操作，拇指为主
  - 文化水平: 高中-本科为主
  - 时间碎片化: 经常一边接电话一边刷手机
```

**设计含义**：
- **字号大**：默认正文 16px，重要信息 20px+
- **行高大**：1.6-1.8（不要紧凑）
- **对比度高**：WCAG AAA 标准
- **拇指可达区**：核心按钮放在屏幕底部
- **信息密度低**：不要塞满，留白足够
- **操作容错**：误触可撤销，不要"操作不可逆"

## 二、设计语言系统（Design System）

### 2.1 品牌色

```
品牌主色（钢蓝 Steel Blue）:
  Primary 500:  #1E5BCC     主按钮、链接、品牌标识
  Primary 400:  #4D7FD9
  Primary 600:  #1849A8
  Primary 100:  #E5EBFF     背景色

辅助色（生命橙 Energy Orange）:
  Accent 500:   #FF7A00     警示、强调、CTA 强化
  Accent 100:   #FFE8D1

中性色（钢灰 Steel Gray）:
  Gray 900:     #1A1A1A     主文字
  Gray 700:     #4A4A4A     次要文字
  Gray 500:     #8C8C8C     辅助文字
  Gray 300:     #D9D9D9     边框
  Gray 100:     #F5F5F5     背景
  Gray 50:      #FAFAFA     页面背景

语义色:
  Success:      #00A86B     成功、上涨
  Warning:      #FFB800     警告、关注
  Danger:       #E63946     错误、下跌、风险
  Info:         #1E5BCC     信息

特殊（钢贸专属）:
  Up（涨）:     #E63946     红色（中国习惯，与股市一致）
  Down（跌）:   #00A86B     绿色
  Neutral:      #8C8C8C
```

### 2.2 字体

```
字体族:
  中文: PingFang SC (iOS) / 思源黑体 / 系统默认
  英文: SF Pro / Inter / Roboto
  数字（金额）: 使用等宽字体（如 SF Mono）

字号系统:
  Display:      32px / 40px lh    (大数字, 如净资产)
  H1:           24px / 32px       (页面标题)
  H2:           20px / 28px       (区块标题)
  H3:           18px / 24px       (卡片标题)
  Body Large:   16px / 24px       (正文)
  Body:         14px / 20px       (次要正文)
  Caption:      12px / 16px       (辅助文字, 如时间戳)
  Small:        10px / 14px       (极少用, 如版权)

字重:
  Regular:      400
  Medium:       500
  Semibold:     600
  Bold:         700

特殊场景:
  金额数字:     等宽 + Semibold + 24px+
  标题:         Semibold 或 Bold
  正文:         Regular
  按钮:         Medium
```

### 2.3 间距系统（8 倍基准）

```
2xs:  4px
xs:   8px
sm:   12px
md:   16px      (默认间距)
lg:   24px
xl:   32px
2xl:  48px
3xl:  64px
```

### 2.4 圆角

```
xs:   4px       (小按钮、Tag)
sm:   8px       (输入框、按钮)
md:   12px      (卡片)
lg:   16px      (大卡片)
xl:   24px      (Modal)
full: 9999px    (圆形头像)
```

### 2.5 阴影

```
none:  无阴影            扁平区域
sm:    0 1px 2px rgba(0,0,0,0.05)       微妙边界
md:    0 4px 8px rgba(0,0,0,0.08)       卡片
lg:    0 8px 16px rgba(0,0,0,0.12)      浮起卡片
xl:    0 16px 32px rgba(0,0,0,0.16)     Modal
```

### 2.6 图标库

```
基础图标库: Lucide Icons / Tabler Icons
钢贸专属图标: 自定义（钢卷/扁担/磅秤/钢厂/...）

图标尺寸:
  16px / 20px / 24px / 32px

图标风格:
  线性图标为主（细线 1.5-2px）
  填充图标用于"已选中"状态
```

## 三、组件库定义

### 3.1 按钮（Button）

#### 类型

```
Primary（主按钮）:
  背景: Primary 500
  文字: 白色
  圆角: sm
  内边距: 12px 24px
  字号: 16px Medium
  Hover: Primary 600
  Disabled: Gray 300 + 不可点击

Secondary（次按钮）:
  背景: 白色
  边框: 1px Primary 500
  文字: Primary 500

Ghost（幽灵按钮）:
  背景: 透明
  文字: Primary 500
  Hover: Primary 100

Text（文字按钮）:
  无背景无边框
  文字: Primary 500

Danger（危险按钮）:
  背景: Danger
  文字: 白色

尺寸:
  Large:    高 48px (主操作)
  Medium:   高 40px (默认)
  Small:    高 32px (次要)
  Mini:     高 24px (Tag 内)
```

#### 关键 CTA 按钮（钢贸特化）

```
"一键报价" / "扫码出库" 等高频按钮:
  - 颜色: Primary 500 + Accent 500 渐变
  - 阴影: lg
  - 字号: 18px Bold
  - 高度: 56px
  - 圆角: md
  - 拇指可达区（屏幕底部）
  - 长按反馈: 缩放 + 振动
```

### 3.2 输入框（Input）

```
基础输入框:
  高度: 44px (确保拇指可点)
  圆角: sm
  边框: 1px Gray 300
  Focus: 2px Primary 500
  文字: 16px (避免 iOS 自动放大)
  内边距: 12px 16px
  Placeholder: Gray 500

特殊输入:
  - 金额输入: 数字键盘 + 大字号 + 等宽字体
  - 手机号: 数字键盘
  - 验证码: 大间距 6 格
  - 搜索: 带搜索图标 + 清除按钮
```

### 3.3 卡片（Card）

```
基础卡片:
  背景: 白色
  圆角: md
  内边距: 16px
  阴影: sm
  
功能卡片（首页大卡片）:
  圆角: lg
  内边距: 20px
  阴影: md
  顶部带渐变色块（强调）

数据卡片（金额展示）:
  数字字号: 32px Bold 等宽
  标签字号: 14px Gray 700
  涨跌色彩: 红/绿
  对比: 大数字 + 小标签
```

### 3.4 列表（List）

```
列表项:
  最小高度: 64px (拇指友好)
  内边距: 16px
  分隔线: 1px Gray 100
  Hover: Gray 50
  Active: Primary 100

复杂列表项:
  - 左侧: 头像/图标
  - 中间: 主标题 + 副标题
  - 右侧: 时间/状态
  - 拖拽/滑动操作
```

### 3.5 表格（Table）

```
PC 端:
  表头: Gray 100 背景, Semibold
  行高: 48px
  斑马纹: Gray 50
  Hover: Primary 100
  排序图标: 在表头右侧
  分页: 在底部居中

移动端:
  表格转卡片（不要在小屏强塞表格）
  每行 = 一张卡片
```

### 3.6 弹窗（Modal）

```
中心弹窗:
  宽度: 90% 屏宽（移动）/ 400-600px（PC）
  圆角: xl
  阴影: xl
  关闭按钮: 右上角
  背景遮罩: rgba(0,0,0,0.5)

底部弹窗（移动端常用）:
  从底部弹出
  圆角: 上方 lg
  最大高度: 80% 屏高
  支持下拉关闭

确认弹窗:
  标题 + 描述 + [取消] [确认]
  危险操作: [确认] 用 Danger 色
```

### 3.7 Toast / 通知

```
Toast（轻提示）:
  位置: 顶部居中（移动）/ 右上角（PC）
  时长: 3 秒
  动画: 淡入淡出
  类型: success / warning / error / info

Notification（通知）:
  位置: 右上角
  时长: 5 秒（可手动关闭）
  支持操作按钮（如"立即查看"）
```

### 3.8 表单（Form）

```
布局:
  Label 在上, 输入框在下（移动友好）
  PC 端可 Label 在左

间距:
  字段间距: lg (24px)
  Label 与输入框: xs (8px)

验证:
  实时验证（onBlur）
  错误信息红字, 在输入框下方
  成功状态: 绿色对勾

必填:
  Label 后红色 *
```

## 七、动效与微交互

### 7.1 通用规则

```
持续时间:
  - 即时反馈（按钮按下）: 100-150ms
  - 局部动效（弹窗）: 200-300ms
  - 页面切换: 300-400ms
  - 全屏动效（首次启动）: 500-800ms

缓动:
  - 优先 ease-out（自然）
  - 弹性效果用 spring
```

### 7.2 关键动效

```
1. 一键报价点击
   - 麦克风图标缩放 + 振动 + 录音波形动画

2. 扫码成功
   - 绿色对勾 + 短促音效 + 进度条增长

3. AI 4 数字加载
   - 4 个数字依次淡入（Stagger 100ms）

4. 资金大盘数字滚动
   - 数字滚动到目标值（CountUp 动画）

5. 锁价倒计时
   - 数字每秒变化 + 最后 10 秒变红色

6. 异常报价提示
   - 红字闪烁 2 次 + 边框抖动

7. 客户确认对账单
   - 大对勾 + 撒花动画
```

### 7.3 加载状态

```
全屏 Loading:
  - Logo + 加载条
  - 不超过 3 秒

局部 Loading:
  - Skeleton 骨架屏（数据卡片）
  - 圆形 Spinner（按钮内）

下拉刷新:
  - Logo 旋转
  - 释放即刷新
```

## 八、可访问性（A11y）

### 8.1 必须遵守

```
颜色对比度:
  - 正文: 7:1 (AAA)
  - 大文字: 4.5:1 (AA)

不仅靠颜色:
  - 涨跌除了红绿, 还有箭头
  - 错误状态除了红色, 还有图标 + 文字

  - 自家"字号设置"入口

操作友好:
  - 所有按钮 ≥ 44×44px
  - 不依赖手势（提供按钮替代）

阅读顺序:
  - 屏幕阅读器友好
  - alt 属性完整

```

  - 关键数据 24px+
  - 行高 1.6+
