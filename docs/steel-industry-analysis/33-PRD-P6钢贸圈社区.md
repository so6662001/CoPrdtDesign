# PRD — P6 钢贸圈社区

> 第 6 个 SaaS 标品的完整 PRD + UI 设计。
>
> **战略定位**：替代微信群（钢贸老板每天刷 800+ 群消息）+ 网络钩（让用户有"等着回复"的事）+ 内容沉淀（结构化、可检索、有 AI 总结）。

---

## 一、产品概述

### 1.1 一句话
> 钢贸老板每天刷 800 条群消息找货 / 看行情 / 八卦——把这些搬到一个"AI 总结 + 结构化 + 征信背书"的社区里。

### 1.2 核心价值
- **效率**：5 分钟读 AI 总结 = 替代 1 小时刷群
- **可信**：每个发言带征信背书，不会被骗
- **沉淀**：所有信息可搜索、可归档
- **流量**：是 P1-P5 的天然导流入口
- **数据**：用户互动数据进数据中台

### 1.3 业务目标（M3-M6）

| 指标 | M3 | M6 |
|---|---|---|
| 注册用户数 | 5,000 | 30,000 |
| DAU | 1,500 | 8,000 |
| 日发帖数 | 200 | 1,500 |
| AI 总结打开率 | 50% | 70% |
| 频道活跃度 | 30% | 60% |

## 四、核心功能详细设计

### 4.1 F6-001 AI 今日要闻总结（核心钩子）

#### 业务流程
```
[每日早 7:30 自动生成]
    └─ AI 抓取过去 24 小时社区内容
    └─ 分类汇总:
        - 行情类: 5 条最重要
        - 政策类: 3 条
        - 钢厂动态: 5 条
        - 招聘类: 2 条
        - 八卦类: 3 条
    └─ 生成结构化摘要
    └─ 推送到首页 + 微信公众号
```

#### 输出形式
```
📣 钢贸圈今日要闻 (4-27)

【行情】
1. 螺纹钢华东上涨 30 元/吨, 主因唐山限产
2. 钢厂出厂价集中上调 (沙钢+50, 中天+80)
3. ...

【政策】
1. 央行 LPR 周三公布
2. ...

【钢厂动态】
1. 沙钢 5 月份出厂价继续上调
2. ...

【招聘】
1. 上海某钢贸招资深业务员, 8-15w
2. ...

【八卦/吐槽】
1. 老板们吐槽: 客户欠款催收难
2. ...

[查看全部 →]
```

```
按品种 (5 个)

  - 板材
  - 管材

  - 线材

  - 华东
  - 华北
  - 华南
  - 西南
  - 西北
  - 东北

按话题 (8 个)
  - 行情解读
  - 政策资讯
  - 招聘求职
  - 行业八卦
  - 技术工艺
  - 找货资源 (公开)
  - 钢厂动态
  - 老板吐槽

特色频道
  - 老赖榜（M5 上线）
  - 钢厂动态
  - 创业者日记 (创始人 IP)
  - 数字化干货 (创始人 IP)
```

#### 频道权限
- 公开频道：所有人可看
- 认证频道：仅认证钢贸 / 钢厂 / 加工 / 物流可看（防止外人混入）
- 付费频道：付费会员可看

### 4.3 F6-003 信用背书（关键差异化）

#### 设计原则
- 用户发言时显示信用标签
- 让"陌生人"变成"可信赖的同行"
- 防止微信群里的诈骗/吹牛/骗货

#### 标签体系
```
✅ 已认证（实名 + 营业执照）
⭐ 钢贸老板 (10 年+ 经验)
🏭 沙钢华东总代理
💯 信用评分 92 (CSC-V0 链路)
✓ 累计成交 5000+ 笔
🚀 平台 Top 100 用户

风险标签:
⚠️ 平台征信黄色 (中风险)
❌ 平台征信红色 (黑名单)
🚫 多次违规
```

#### 关键展示位
- 帖子作者旁
- 评论者旁
- 私聊发起前必查（弹征信预览）

### 4.4 F6-004 暗池找货（与战略 09/11 对齐）

> **不做公开比价**，做"私域 + 定向匹配"：

```
[用户在"找货资源"频道发布需求]
  例: "Φ16 螺纹 8 吨 北京急用"
    └─ 默认仅认证用户可见
    └─ 平台 AI 后台分析:
        - 该用户的征信
        - 区域
        - 紧急度
    └─ 系统不广播
    └─ 仅给"可能有货且非竞争"的卖家定向推送
        - 卖家私下回复 "有货, 4170, 12:00 前提"
    └─ 买家选 1 家私聊成交
    └─ 不公开报价对比
```

### 4.5 F6-005 老赖榜（M5 上线，强 PR 事件）

#### 设计要点
- 每月 1-3 号发布
- 基于平台真实数据 + 用户认证
- 严格审核（避免名誉权风险）
- 申诉机制完整

#### 展示形式
```
钢贸圈本月老赖榜 (4 月)

⚠️ 本榜单基于平台 2000+ 钢贸商提供数据 + 司法公开记录
⚠️ 上榜方有申诉权 (5 个工作日内回复)

❌ 一级失信
1. XX 建工有限公司 (上海)
   - 累计欠款: 850 万 (在 12 家钢贸商处)
   - 平均逾期: 180 天
   - 司法记录: 3 起被执行
   - 状态: 法人变更, 疑似跑路

❌ 二级警示
2. ...

⚠️ 中风险
3. ...

[完整榜单] [申诉通道]
```

#### 商业意义
- 行业内强 PR 事件，每月引爆传播
- 让钢贸圈知道"钢链通有数据有立场"
- 推动用户主动加入"贡献数据 = 享受查询"

```
    └─ 点 [私聊]
        └─ 弹窗:
            "您即将私聊 [B 的名字]

            - 实名认证 ✓
            - 钢贸老板 (5 年)
            - 信用评分: 75 (B 级)
            - 历史成交: 230 笔
            - 风险标签: 无
            
            建议:
            - 首次合作不要赊销
            - 大额交易走平台担保
            
            [继续私聊] [取消]"
        └─ 用户确认 → 进入聊天
```

### 4.8 F6-008 内容审核（自动 + 人工）

#### 自动审核
```
违规内容自动拦截:
  - 涉黄/涉政/暴恐
  - 广告/推广 (与"找货"区分)
  - 个人信息泄露 (手机/身份证)
  - 攻击性言论

警告内容人工 review:
  - 涉及具体公司的负面信息
  - 老赖举报 (必须人工)
  - 价格信息 (避免操纵市场)
```

#### 用户分级
- 新用户：发帖前审核
- 老用户（30 天+ 无违规）：先发后审
- KOL：先发后审
- 高频违规：禁言/封号

## 六、数据模型

```
Channel (频道)
  - id / name / type (品种/区域/话题/特色)
  - description / member_count
  - is_certified_only / is_paid

Post (帖子)
  - id / channel_id / author_user_id / tenant_id
  - title / content / images[] / videos[]
  - visibility (public/certified/circle)
  - status (active/审核中/被屏蔽)
  - like_count / comment_count / view_count

Comment (评论)
  - post_id / user_id / content / parent_comment_id

InquiryPost (找货帖)
  - post_id / sku / quantity / region / urgency
  - matched_sellers[]

UserCertification (用户认证)
  - user_id / cert_type (real_name/business/tier)
  - tier (普通/钢贸老板/总代/KOL)
  - tags[]

OldDebtorBoard (老赖榜)
  - period / debtor_company / total_debt
  - affected_traders_count / avg_overdue_days
  - level (一级/二级/中风险)
  - status (publish/appeal/removed)

ContentAuditLog (审核)
  - post_id / auditor / decision / reason
```
