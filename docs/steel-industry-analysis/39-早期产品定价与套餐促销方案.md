## 一、定价哲学

### 1.1 三大原则

| 原则 | 说明 |
|---|---|
| **价值定价**（Value-Based） | 不按"成本+利润"定价，按"客户能省/能赚"定价 |
| **分层套餐**（Tiered） | 给客户"明显升级理由"，让小客户能买得起，大客户愿意多付 |
| **按需付费**（Usage-Based 部分） | 高频使用付更多，低频用户保留免费基础版 |

### 1.2 钢贸客户付费心理（来自 06 号访谈洞察）

```
钢贸老板的"付费 5 大理由"（按强度排序）:
  1. 我能省钱 (最强动机, 比如金融业务省利息)
  2. 我能省时间 (业务员效率提升)
  3. 我能避坑 (征信查询)
  4. 我能赚更多 (集采联盟)
  5. 我能管好团队 (业务员风控)

钢贸老板的"付费 3 大障碍":
  1. 不愿"按月订阅" (习惯一次性付)
  2. 担心"绑死" (希望能随时退出)
  3. 不愿"被收割" (担心后续涨价)

定价策略应对:
  - 主推年付 (一次性, 不是按月)
  - 7 天无理由退款
  - 锁定首年价格 (老客户续约不涨价)
```

## 三、促销策略（M3-M12 分阶段）

### 3.1 阶段一：M3-M6 早期客户拉新（重价格优惠）

#### 策略 A: "首年立减 50%"
```
适用: 业务版 + 企业版
立减: 50%
  - 业务版: 4,980 → 2,490
  - 企业版: 19,800 → 9,900

条件:
  - 仅限 ERP 老客户 (前 2000 家)
  - M3-M6 内购买
  - 一次性年付

理由:
  - 老客户已建立信任, 转化最快
  - 50% 让利是行业冲击力价格
  - 锁定 1 年, 锁定续约
```

#### 策略 B: "免费试用 30 天 + 自动转付费"
```
所有套餐:
  - 注册即免费试用 30 天
  - 30 天内可随时退订
  - 30 天后自动转付费 (但提前 7 天提醒)

理由:
  - 降低决策门槛
  - 让用户先体验价值
  - 自动转付费提升转化
```

#### 策略 C: "5 家种子客户终身免费"
```
W4 招募的 5 家种子:
  - 终身免费企业版
  - 不收任何 SaaS 费
  - 但加值服务（金融/集采）按标准

理由:
  - 表达诚意
  - 形成强力背书
  - "免费的代言人"传播
```

#### 策略 D: "老带新双向激励"
```
老客户推荐 1 个新客户成功签约:
  - 老客户得: 续约费 50% 减免 (最多 100% 抵扣)
  - 新客户得: 首年 30% 优惠

如果老客户推荐 5 个:
  - 终身免费基础版

理由:
  - 用老客户撬新客户
  - 单客获客成本极低
  - 钢贸圈口碑效应强
```

### 3.2 阶段二：M7-M12 规模化（重价值塑造）

#### 策略 E: "套餐升级激励"
```
业务版客户升级到企业版:
  - 抵扣已付费部分
  - 额外送 2 个月企业版

企业版客户升级集团版:
  - 抵扣 + 额外送 3 个月
  - 免费实施服务

理由:
  - 客户升级 = NDR 提升
  - 比拉新便宜 5-10 倍
```

#### 策略 F: "数据贡献激励"
```
开通"数据贡献授权" 的客户:
  - 业务版: 减免 500 元/年
  - 企业版: 减免 2,000 元/年
  - 集团版: 减免 5,000 元/年

理由:
  - 数据贡献者越多, 数据中台越值钱
  - 每年减免远低于数据本身的商业化价值
  - 双赢 (客户省钱, 平台拿数据)
```

#### 策略 G: "集采联盟绑定"
```
加入集采联盟 (基础免费):
  - 必须开通企业版以上
  - 享受集采价格 (每吨省 30-80 元)
  - 月度 5 万吨集采的, 年省 ≥ 100 万

理由:
  - 集采是钢贸老板"省钱"的最大触发点
  - 用集采价值锁定企业版续约
```

### 3.3 阶段三：M12+ 收入结构升级（重金融分润）

```
M12+ 重心:
  - SaaS 订阅 (基础) → 50% 收入
  - 金融分润 (高毛利) → 30% 收入
  - 数据指数 (高价值) → 15% 收入
  - 其他 → 5%

定价策略:
  - SaaS 价格保持稳定 (不涨价)
  - 重点推金融业务 (高毛利)
  - 数据指数对外 (M18+)
```

## 六、退款与续约政策

### 6.1 退款政策

```
30 天无理由退款:
  - 注册 30 天内, 任何套餐
  - 全额退款
  - 不需要理由
  - 1 个工作日到账

7 天体验包:
  - 任何用户 (含老客户) 升级套餐前
  - 7 天体验, 不满意全退

不可退款:
  - 加值服务 (一次性产品/服务)
  - 已使用超过 30%（按用量算）的部分
```

### 6.2 续约政策

```
老客户续约:
  - 价格锁定 (首年价 / 不涨价)
  - 提前 30 天提醒
  - 续约送 1 个月（变相 8% 优惠）
  - 自动续约可手动关闭

升级激励:
  - 业务版升企业版: 抵扣已付费 + 送 2 个月
  - 企业版升集团版: 抵扣 + 送 3 个月 + 免费实施

降级:
  - 允许降级 (不强制锁定)
  - 已付费部分按比例退还
```

### 6.3 流失挽回

```
30 天未活跃:
  - 客户成功电话回访
  - 询问原因 + 提供帮助

60 天未活跃:
  - CEO/总裁亲自微信问候
  - 提供 1 个月免费续约

90 天未活跃:
  - 价格下调 50% 挽回
  - 或者免费降级到基础版 (保留客户)

不要的客户:
  - 投诉率高
  - 恶意退款
  - 拖欠款
  - 平台拉黑
```

## 九、风险与应对

| 风险 | 影响 | 应对 |
|---|---|---|
| 价格被同行模仿 | 价格战 | 突出差异化 (数据/AI/合规), 不打价格战 |
| 客户嫌贵 | 转化低 | 强化"省了多少"案例 + 试用期 + 老带新 |
| 续约率低 | 收入不稳 | 客户成功投入 + 续约前 30 天密集触达 |
| 退款率高 | 财务波动 | 试用期内主动提供帮助, 真出问题快退 |
| 集采承诺不达 | 信任崩塌 | 集采前明确预期 + 兜底机制 |
| 金融业务出风险 | 重大损失 | 持牌方主体 + 保险兜底 + 风控严控 |

## 十一、最终结论

> **早期定价的本质是"用价格信号传递产品价值"。**
>
> **关键判断**:
> 1. **企业版 ¥ 19,800/年** 是核心套餐 (主力客户群)
> 2. **业务版作为入门级** 降低试用门槛 (后续升级)
> 3. **集团版作为利润放大器** (单客高价值)
> 4. **加值服务（金融/数据/集采）** 是 M7+ 收入主引擎
>
> **促销节奏**:
> - M3-M6 重价格 (50% 立减 + 老带新)
> - M7-M12 重价值 (升级 + 数据贡献激励)
> - M12+ 重金融 (分润业务)
>
> **不做的事**:
> - ❌ 不打价格战
> - ❌ 不做"按月收费" (老板不喜欢)
> - ❌ 不强制绑定金融业务
> - ❌ 不"一次性涨价"老客户
>
> **3 年目标**: ARR 30 亿, 付费客户 10 万家, NDR 130%+
