# 钢铁行业全景痛点与产品策略分析

> 面向钢铁贸易、钢铁生产制造（民营）、钢材加工三大类客户，按规模分层进行核心痛点分析，并给出"不得不用"的功能清单、产品优化建议与落地方案推荐。

---

## 一、整体行业背景判断（先建立共识）

钢铁行业有几个共性特征，决定了所有软件方案的底层逻辑：

1. **重资产、低毛利、高周转**：1% 的库存周转率提升 = 几百万利润，因此"库存"和"资金"是命门。
2. **价格波动剧烈**：钢价一天可能波动 50–200 元/吨，**实时价格 + 锁价 + 套保**是核心竞争力。
3. **一物一码 / 一支一码**：钢材有炉批号、质保书、米数/重量双计量（理计 vs 过磅），这是与一般制造业最大的差异。
4. **物流成本占比高**：运费 80–300 元/吨，物流协同直接影响利润。
5. **金融属性强**：托盘、仓单质押、承兑汇票、保理是常态，软件必须能"对接资金"。
6. **政策驱动**：环保限产、碳排放、超低排放、合规发票（金税四期）是高压线。

## 二、按"企业类型 × 规模"拆解痛点矩阵

### A. 钢铁生产制造企业（民营）

#### A1. 管材生产企业（焊管、无缝管、方矩管）

| 规模 | 核心痛点 | 不得不用（刚需） |
|---|---|---|
| **小型**（年产<10万吨） | 1) 订单小批量多规格，排产靠人脑；2) 原料（带钢/钢坯）采购吃价差，库存死压资金；3) 一支管子一个炉批号，质保书手工开 | **基础ERP+磅房系统+质保书自动生成**；微信下单接单工具 |
| **中型**（10–50万吨） | 1) 多机组排产冲突（高频焊机、定径机切换损耗大）；2) 钢卷剩余余料追溯难；3) 销售合同与生产协同脱节；4) 客户要 SAP/EAS 对接 | **MES（排产+机组数采）+ WMS（一支一码）+ 钢卷余料管理 + EDI对接** |
| **大型**（>50万吨） | 1) 多基地协同；2) 能耗/碳排放管控；3) 合金/废钢配比优化；4) 出口订单多语种、多币种、信用证 | **APS高级排产 + 能源管理EMS + 碳资产平台 + 集团财务共享 + 国际贸易模块** |

#### A2. 型材生产企业（H型钢、角钢、槽钢、轨道）

| 规模 | 核心痛点 | 不得不用 |
|---|---|---|
| **小型** | 模具/孔型管理乱，换辊浪费严重；定尺非定尺切割损耗高 | **简易MES + 孔型/模具台账 + 切割优化** |
| **中型** | 大客户（基建/船厂）按图下单；负差控制（少给 0.5% 就是利润）；运输用半挂还是火车皮算不清 | **项目型订单管理 + 负差/正差实时管控 + 运输配载优化** |
| **大型** | 与设计院BIM协同；按工程项目交付（一栋楼分批送）；与中铁/中建对接ERP接口 | **BIM+项目交付平台 + 集团级SRM/CRM + 政府客户合规模块** |

#### A3. 镀锌板/冷板生产企业

| 规模 | 核心痛点 | 不得不用 |
|---|---|---|
| **小型** | 锌液成分控制；表面缺陷漏检；客户投诉多 | **基础MES + 锌液配方管理 + 在线检测对接** |
| **中型** | 多客户多牌号（DX51D、SGCC等）切换；包装方式复杂；汽车板/家电板要 IATF 16949 / VDA 6.3 体系 | **质量追溯到卷+客户专属包装规则+体系合规模块（FMEA/SPC/MSA）** |
| **大型** | 与汽车主机厂JIT/JIS交付；EDI/VDA 4905 报文；质量异议追溯到分钟级；颜色/光泽度复检 | **车规级质量平台 + EDI/VDA + APS + 数字孪生产线** |

#### A4. 无缝钙丝（包芯线）生产企业 — 冶金辅料/炼钢辅料

| 规模 | 核心痛点 | 不得不用 |
|---|---|---|
| **小型** | 粉剂配方保密；包芯均匀度控制；客户分散（中小钢厂） | **配方加密管理 + 简易MES + 客户拜访CRM** |
| **中型** | 多牌号包芯线（钙线、纯钙、硅钙、碳线）切换；钢厂招投标周期长、账期长 | **配方版本管理+招投标管理+应收账款风控** |
| **大型** | 直供大型钢厂（沙钢、中天等），需进入合格供应商体系；冶金效果数据反向追溯 | **SRM对接+冶金效果数据平台+VMI寄售库存** |

---

### B. 钢材加工企业（剪切、纵剪、开平、激光切割、来料加工）

| 规模 | 核心痛点 | 不得不用 |
|---|---|---|
| **小型** | 来料代加工的料账和钱账分不清；边角料管理乱；加工费结算扯皮 | **客户寄存库存账（料账独立）+ 加工工单 + 边角料回收台账** |
| **中型** | 套裁优化（一卷板裁多少种规格利润最大）；多台剪切线排产；运输配载 | **套裁优化算法 + 排产看板 + TMS** |
| **大型** | 服务多个下游行业（家电、汽车、集装箱）规则各异；JIT配送；与下游MES打通 | **行业化配置平台 + JIT/SMI + 数据中台 + 客户门户** |

---

### C. 钢贸企业

#### C1. 现货批发商（仓库型，往往挂靠大型钢厂代理）

| 规模 | 核心痛点 | 不得不用 |
|---|---|---|
| **小型**（年销<5万吨） | 1) 价格随行就市，毛利薄如纸；2) 一支货卖给谁、毛利多少全凭经验；3) 资金紧张，靠承兑周转 | **进销存+磅单+承兑汇票管理+老板手机看实时盈亏** |
| **中型**（5–30万吨） | 1) 多仓多品类，库存账实不符；2) 业务员私单飞单；3) 仓单质押融资需求 | **WMS+一物一码+业务员行为风控+仓单质押对接（如欧冶云商/上海钢联）** |
| **大型**（>30万吨） | 1) 多基地、多事业部、集团并表；2) 期现套保策略执行；3) 上下游产业链金融 | **集团ERP+期现一体化平台+供应链金融SaaS+BI驾驶舱** |

#### C2. 零售商（终端门店，工程零售/工地配送）

| 规模 | 核心痛点 | 不得不用 |
|---|---|---|
| **小型** | 散单多、规格杂、欠款多；老板娘记账本 | **微信小程序下单+电子磅单+对账单一键发送+应收账款催收** |
| **中型** | 工地客户多、回款慢；工程项目分批送货；运费谁出扯皮 | **项目管家+送货排程+回款看板+司机APP** |
| **大型** | 区域连锁；标准化定价规则；新零售（线上+线下） | **连锁门店管理+动态定价引擎+线上商城+会员体系** |

#### C3. 服务商 / 调货公司（撮合+垫资为主，自己不一定有库存）

| 规模 | 核心痛点 | 不得不用 |
|---|---|---|
| **小型** | 全靠人脉和电话；找货效率低；货款风险大 | **手机端找货+资源圈（类似找钢网）+合同/收付款台账** |
| **中型** | 资源池散落在Excel和微信群；垫资风险控制；多方对账复杂 | **资源池SaaS+三方对账+授信额度管理+电子合同** |
| **大型** | 平台化（既是贸易商又是服务平台）；上下游撮合佣金 | **B2B交易平台+SaaS赋能下游+撮合+金融科技** |

## 三、跨类型共性"不得不用"的能力（产品规划必须命中的"非买不可"清单）

按"如果没有就活不下去"排序：

1. **磅房 / 一物一码 / 质保书系统** — 钢铁行业第一刚需，没有就没法做生意。
2. **金税四季合规开票 + 承兑汇票 / 电子商票管理** — 财税合规底线。
3. **库存账实一致 + 多计量单位（理计/过磅/支/捆/件）** — 钢材库存独有难点。
4. **价格管理（成本核算到一支/一卷 + 实时调价 + 锁价单）** — 决定毛利。
5. **手机端 / 老板驾驶舱** — 老板必须能在手机看库存、应收、毛利。
6. **客户/供应商授信与风控** — 钢铁行业坏账多，必须管。
7. **物流协同（车辆调度 + 运费结算 + 司机APP + 电子签收）** — 运费占成本大头。

## 四、产品策略优化建议

### 1. 产品矩阵建议：双轨制 + 模块化

不要做"一个大ERP通吃"，建议分成两条产品线：

- **轻量SaaS版**（针对小型、零售、调货）：手机优先、年费 5k–3w、3天上线、按账号收费。
- **行业化PaaS+SaaS**（针对中大型生产/加工/批发）：低代码平台 + 行业模板（管材/型材/镀锌/冷板/钙丝/批发/加工各一套），按用户数+模块收费。

中间用**统一数据中台 + 业务中台**，避免两条线脱节。

### 2. 差异化突破口（避开用友/金蝶/管家婆的红海）

| 突破口 | 说明 |
|---|---|
| **"一支钢"全生命周期** | 从钢厂炉号→贸易仓→加工→工地，做出一物一码穿透追溯（这个用友做不到） |
| **期现一体化** | 集成上海期货所行情，把期货套保和现货库存联动算盈亏 |
| **AI 报价 / AI 调货** | 基于历史成交+实时市场，给业务员推荐报价区间和调货资源 |
| **产业链金融** | 与银行/保理公司打通，把ERP数据变成融资授信依据，可收金融分润 |
| **碳资产 + 超低排放** | 政策红利，生产企业必装，未来3年强需求 |

### 3. 客户成功 / 商业模式建议

- 小客户：**SaaS年费 + 微信生态获客**（重点投入抖音/视频号短视频获客，钢贸老板都在刷）。
- 中客户：**SaaS年费 + 实施一次性费用 + 模块按需开通**（关键是行业模板要够厚，3周上线）。
- 大客户：**定制+订阅+数据增值服务**（数据驾驶舱、行业指数、金融对接均可二次收费）。

## 五、落地方案推荐（分阶段路线图）

### 阶段一：稳基本盘（先聚焦一个细分做深）

**建议优先选择"中型钢贸批发商"作为切入点**，理由：

- 数量大（全国 5w+ 家），付费意愿明确（已经在用Excel/管家婆但都不好用）。
- 决策链短（老板说了算）。
- 痛点清晰（库存+资金+业务员管控）。
- 能快速形成口碑（钢贸圈子小，一个市场拿下就能滚雪球）。

交付物：

- WMS（一物一码、磅单、质保书）
- 进销存（多计量、锁价单、毛利核算到支）
- 财务（承兑、应收、对账单一键发）
- 老板驾驶舱（手机端）
- 业务员APP（找货、报价、签合同）

### 阶段二：横向扩品类（生产 + 加工）

- 把钢贸客户的下游加工厂、上游小钢厂顺势打通，形成**产业链SaaS**。
- 重点做"钢厂直供→贸易商→加工厂→工地"的**一物一码穿透**，这是护城河。

### 阶段三：平台化 + 金融化

- 把客户的库存、应收、订单数据沉淀，开放给金融机构，做**仓单质押 / 订单融资 / 保理**。
- 引入期货行情，做**期现套保SaaS**。
- 做行业**指数 / 报告 / 数据服务**，二次变现。

### 阶段四：AI Agent化（这是未来3年的窗口）

- "AI业务员"：自动找货、自动报价、自动催收。
- "AI老板"：自动盯盘、自动预警库存/资金/毛利异常。
- "AI客服"：自动回复客户询价、发送对账单。
- 这一波 AI 能力，是甩开传统ERP厂商的最大机会。

---

## 六、三条最关键的建议（如果只能记住三句话）

1. **不要做大而全，先做"中型钢贸批发"打透打穿，再横向复制**。这是 ROI 最高的切入点。
2. **把"一物一码 + 期现一体化 + 产业链金融"做成你产品的三大护城河**，传统ERP做不了，新势力没行业know-how，这是你的窗口。
3. **All in 移动端 + AI Agent**。钢铁行业老板年龄偏大但极度依赖手机微信，做手机端体验和 AI 助手，比做PC端功能更能打动人。
