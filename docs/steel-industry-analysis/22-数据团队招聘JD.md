### 2.1 JD 1：首席数据官（CDO）

```
【职位】首席数据官 CDO（Chief Data Officer）
【部门】数据中心（直接向 CEO 汇报）
【地点】[上海 / 北京 / 杭州]
【薪资】200–400 万年薪 + 期权 0.5%–2%
【招聘紧迫度】★★★★★

【公司介绍】
我们正在打造"懂钢贸的中国版 Salesforce + 行业版彭博"——
基于 2,000+ 钢贸企业 ERP 真实数据，构建产业 SaaS + 数据指数 + 轻资产生态运营三大引擎。
3 年内目标 ARR 28 亿，估值 250–500 亿。

【岗位职责】
1. 制定公司数据战略，把数据资产打造为公司最大护城河
2. 主导建立钢贸真实交易数据指数体系（CSP/CSC/CMP/CSI/CFP 5 大指数）
3. 主导数据资产商业化（数据指数订阅 / API / 联合风控 / 数据增信）
4. 领导数据团队（M12 8 人 → M36 25 人）
5. 与四大合作完成数据资产评估、入表
6. 与银行、保险、对冲基金、政府等客户深度合作
7. 监管对接（央行 / 网信办 / 数据交易所）
8. 数据合规与安全的最高负责人

【任职要求】

必备：
- 10 年+ 数据相关行业经验，5 年+ 高管经验
- 在以下任一类型公司有核心高管经历：
  * 头部数据/金融科技公司（彭博/路透/Wind/同花顺/百行征信）
  * 大型银行/保险公司数据部门（建行/工行/平安/人保等）
  * 头部产业互联网公司（找钢网/欧冶云商/京东工业品/震坤行）
  * 大型互联网公司数据中台（阿里/腾讯/美团数据中台）
- 主导过亿级用户/亿级数据规模的数据产品或平台
- 深刻理解数据合规（个保法/数据安全法/征信业管理条例）
- 熟悉数据资产估值、入表会计处理（新规）

加分：
- 钢铁/大宗商品/B2B 行业背景
- 创业公司高管经验
- 数据交易所/数据信托落地经验
- 金融牌照申请经验

【硬条件】
- 985/211 大学本科以上（计算机/数学/统计学优先）
- 普通话流利，英文工作能力
- 接受高强度工作（创业期）

【加分简历关键词】
彭博 / 路透 / Wind / 同花顺 / 百行征信 / 朴道征信 / 平安数据 / 微众银行 /
找钢网数据 / 欧冶云商数据 / 京东数科 / 蚂蚁金服 / 数据中台 / 数据资产 /
银行数据 / 风控建模 / 联合建模 / 数据交易

【应聘方式】
邮件 hr@gangliantong.com 标题"CDO-姓名-城市"
联系电话：[HR 联系人]
```

### 3.3 高管招聘的"创始人面试 SOP"

```
1. HR 初筛 → 简历筛选 + 电话沟通（30 分钟）
2. 业务部门负责人面试 → 专业能力（1.5 小时）
3. CEO 面试 → 战略契合度（1.5 小时）
4. 联合创始人 / 投资人面试（视情况）
5. 背景调查 → 5+ 个 reference call
6. 谈薪 → 期权 / 现金 / 福利方案
7. Offer 后 onboarding（30 天计划）
```

### 3.4 创始人/CEO 必须亲自做的事

- 与 CDO / CRO / CCO 候选人**至少见 3 次面**（首次接触 → 业务对话 → 价值观共鸣）
- 与 ≥ 2 个 reference 进行电话调研
- **不要省"半天对话"——这是高管入职的关键**
- 入职后 3 个月内每周 1v1，6 个月后双周 1v1

## 四、薪酬与期权设计

### 4.1 高管薪酬架构

| 岗位 | 现金（年） | 期权（公司比例） | 业绩对赌 |
|---|---|---|---|
| CDO | 200–400 万 | 0.5%–2% | 数据收入 KPI |
| CRO | 150–300 万 | 0.3%–1% | 不良率 / 风险 KPI |
| CCO | 80–150 万 | 0.1%–0.3% | 合规零事故 |
| 数据架构师 | 100–150 万 | 0.05%–0.1% | 系统稳定性 |
| 数据 BD 总监 | 80–200 万 + 提成 | 0.1%–0.3% | 销售目标 |

### 4.2 期权解禁规则

- **4 年解禁**：第 1 年 25%（cliff），后 3 年每月 1/36
- **加速条款**：IPO 时剩余期权 50% 立即解禁
- **离职处理**：未解禁部分回收 / 已解禁部分按公司规定回购

### 4.3 业绩对赌典型条款

```
CDO 对赌示例：
- M12 数据相关收入达成 ≥ 80% 目标 → 期权 100% 保留
- M12 数据相关收入达成 60–80% → 期权 50%
- M12 数据相关收入达成 < 60% → 期权回收，可能调岗

CRO 对赌示例：
- M12 不良率 ≤ 0.5% → 100% 保留
- 不良率 0.5%–1% → 50%
- 不良率 > 1% → 调岗或离职
```
