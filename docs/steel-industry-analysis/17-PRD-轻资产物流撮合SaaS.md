# PRD — 轻资产物流撮合 SaaS

> 本文是 14 号文档"引擎三：轻资产生态运营"中"物流撮合"子业务的完整 PRD。
>
> **核心立场**：钢材物流是真实痛点（找钢网/胖猫验证过），但**自建物流是重资产陷阱**——找钢网为此付出巨大代价。我们要做的是 **"轻资产撮合 + SaaS 工具 + 战略合作"**，让平台成为钢材物流的"调度大脑"和"基础设施提供方"，而不是物流公司。
>
> 适用读者：产品经理、研发、BD（物流公司合作）、客户成功。

---

## 一、业务定位与边界

### 1.1 一句话定位

> **钢材物流的"调度大脑 + SaaS 工具" —— 不持车、不雇司机、不上保险，靠"流量+工具+数据"赚分润。**

### 1.2 关键边界

| 不做 | 做 |
|---|---|
| ❌ 自建车队 | ✅ 撮合社会运力 |
| ❌ 雇佣司机 | ✅ 司机端 SaaS / 派单工具 |
| ❌ 自营仓储 | ✅ 仓储端 SaaS |
| ❌ 自买保险（承保） | ✅ 保险代理 / 分销 |
| ❌ 重资产 | ✅ 轻资产分润 |

### 1.3 服务对象

- **货主端**：钢贸商、加工厂、采购方（货从哪到哪谁出钱）
- **承运端**：专业钢材物流公司、社会运力（货拉拉/满帮）、自有车队
- **司机端**：钢材货车司机
- **仓储端**：监管仓、社会仓、加工厂仓库

## 二、行业痛点与设计哲学

### 2.1 钢材物流的 6 大真痛点

| # | 痛点 | 现状 | 平台机会 |
|---|---|---|---|
| 1 | **运费议价不透明** | 货主每次电话议价，被司机坑 | 平台报价透明 + 历史价 |
| 2 | **装卸效率低** | 排队/装错货/扯皮 | 平台扫码装卸 + GPS 追踪 |
| 3 | **空驶率高** | 30–40% 空驶 | 平台撮合返程货 |
| 4 | **运费结算慢** | 30–60 天才结清 | 平台代收代付 + T+1 结算 |
| 5 | **货物风险大** | 钢材掉货/被盗/损坏 | 保险绑定 + 视频监控 |
| 6 | **司机收款风险** | 货主不付运费 | 平台担保结算 |

### 2.2 与找钢网"胖猫物流"的差异化

| 维度 | 胖猫（重资产） | 我们（轻资产） |
|---|---|---|
| 模式 | 自营车队+司机 | 撮合社会运力 |
| 投入 | 数十亿（车+人） | 软件+运营 |
| 毛利率 | 5–10% | 30%+（分润） |
| 扩张速度 | 慢（要买车） | 快（接 API） |
| 城市覆盖 | 受车队规模限制 | 全国（社会运力天然覆盖） |

### 2.3 设计哲学

- **平台不持有任何物流资产**（车/人/仓/保险都不直接持有）
- **平台是"调度大脑"**（用算法+数据让现有运力更高效）
- **平台是"信任中介"**（担保结算/保险绑定/质量评分）
- **平台是"SaaS 工具提供商"**（卖给物流公司提升其效率）

## 三、3 大产品模块

### 3.1 模块 A：货主端 — 智能派单 SaaS

#### 3.1.1 业务目标

让货主一键派单 → 自动找最优运力 → 全程可视 → 收货签收。

#### 3.1.2 核心流程

```
[货主在 SaaS 平台]
    └─ 选择"发货"
        └─ 输入：起点 + 终点 + 货品 + 重量 + 时效要求
            └─ 平台 AI 报价（基于历史价 + 市场价 + 距离 + 货类）
                └─ 货主确认价格 / 修改 / 议价
                    └─ 平台广播给候选运力（按距离+评分+历史合作）
                        └─ 运力接单（5 分钟内未接单则扩大范围）
                            └─ 自动生成运输合同
                                └─ 司机扫码装车（与扫码出库联动）
                                    └─ 全程 GPS 追踪
                                        └─ 客户收货 + 电子签字
                                            └─ 平台确认 → T+1 结算给运力
                                                └─ 货主付款给平台（30 天内）
```

#### 3.1.3 关键功能

| ID | 功能 | 优先级 |
|---|---|---|
| L-001 | 一键派单（输入起终点+货品） | P0 |
| L-002 | AI 智能报价（历史价+市场价+距离） | P0 |
| L-003 | 自动撮合社会运力（按距离+评分） | P0 |
| L-004 | 司机扫码装车（联动扫码出库 SaaS） | P0 |
| L-005 | 全程 GPS 追踪 + 异常预警 | P0 |
| L-006 | 客户收货 H5（验货+电子签） | P0 |
| L-007 | 担保结算（货主付平台→平台付司机） | P0 |
| L-008 | 运费报告 / 历史价分析 | P1 |
| L-009 | 司机评分 / 黑名单 | P1 |
| L-010 | 与扫码出库 / 资金大盘联动 | P0 |

### 3.2 模块 B：承运端 — 物流公司 SaaS

#### 3.2.1 业务定位

把"专业钢材物流公司 / 中型车队"变成平台的合作伙伴，给他们提供 SaaS 工具提升效率，平台分润。

#### 3.2.2 核心功能

| ID | 功能 | 优先级 |
|---|---|---|
| L-101 | 多车多司机管理 | P0 |
| L-102 | 派单 / 调度 / 路径优化 | P0 |
| L-103 | 司机绩效管理 | P0 |
| L-104 | 油费 / 维修 / 保险管理 | P1 |
| L-105 | 保险智能投保 | P1 |
| L-106 | 与平台货源池打通（接平台派单） | P0 |
| L-107 | 财务自动核算 / 月度结算 | P1 |

#### 3.2.3 商业模式

- 物流公司 SaaS：4980 元/年/家（前 100 家免费）
- 平台派单分润：每单收物流公司 5%

### 3.3 模块 C：司机端 — 司机 APP

#### 3.3.1 业务定位

直接服务个体司机，让他们有持续货源 + 工具支持 + 收款保障。

#### 3.3.2 核心功能

| ID | 功能 | 优先级 |
|---|---|---|
| L-201 | 接单 / 抢单 | P0 |
| L-202 | 导航 / 路径优化 | P0 |
| L-203 | 装车扫码 / 卸车签收 | P0 |
| L-204 | 拍照存证 / 视频回传 | P0 |
| L-205 | 一键投诉 / 求助 | P0 |
| L-206 | 收款 T+1 到账 | P0 |
| L-207 | 加油 / 维修券（与油卡公司合作） | P1 |
| L-208 | 司机社区 / 互助 | P1 |

#### 3.3.3 商业模式

## 四、数据模型

```
LogisticsOrder (运单)
  - id, shipper_tenant_id, receiver_id
  - origin, destination, distance_km
  - cargo_type, weight, packaging
  - quoted_price, actual_price
  - assigned_carrier_id, driver_id
  - status (pending/quoted/assigned/loading/transit/delivered/closed/disputed)
  - delivery_order_id (联动出库 SaaS)

CarrierProfile (运力档案)
  - id, type (carrier_company/individual_driver)
  - vehicle_count, capacity
  - service_areas, specialties
  - rating, total_orders, dispute_rate
  - status (active/suspended/blacklisted)

DriverProfile
  - id, name, license, vehicle_no
  - belongs_to_carrier (可空，独立司机为空)
  - rating, anomaly_count
  - bank_info (T+1 结算用)

GPSTracking
  - order_id, timestamp, lat, lng
  - speed, status

LogisticsPayment
  - id, order_id
  - shipper_pay_amount, carrier_get_amount
  - platform_fee, platform_fee_rate
  - escrow_status (held/released)

LogisticsDispute
  - id, order_id
  - type (delay/damage/loss/wrong_quantity/payment)
  - severity, evidence
  - resolution, settled_at
```

## 五、商业模式

### 5.1 收入分类

| 收入项 | 计费方式 | 月营收预测 (M12) |
|---|---|---|
| **平台撮合费**（货主端） | 单笔 1–3% 货运费 | 80 万 |
| **物流公司 SaaS** | 4,980/年/家（M12 100 家） | 8 万 |
| **司机端增值**（油卡/保险/ETC） | 分润 | 30 万 |
| **保险分销** | 分润 20–30% | 20 万 |
| **担保结算资金占用** | 平均 14 天 × 年化 8% | 12 万 |

**M12 月营收**：约 **150 万 / 年化 1,800 万**
**M24**：约 **800 万 / 年化 1 亿**
**M36**：约 **2,500 万 / 年化 3 亿**

### 5.2 不靠"司机端付费"赚钱

司机端永远免费——这是关键差异化（货拉拉/满帮一直被诟病"对司机收费过重"）。

我们靠：
- 货主端撮合费（1–3%）
- 物流公司 SaaS 订阅
- 保险/油卡/ETC 分润

## 六、与其他 SaaS / 业务的联动

### 6.1 与扫码出库 SaaS 联动

- 出库扫码 → 自动触发派单
- 司机扫码装车 → 自动同步出库状态
- 验货签收 → 自动触发结算 + 应收入账

### 6.2 与资金大盘 SaaS 联动

- 运费应付自动入账
- 担保资金占用可视
- 物流相关账单一键导出

### 6.3 与金融业务联动

- 担保结算（货主付钱进平台 → 验货后付司机）
- 司机端"运费保理"（T+0 拿到 95% 运费）— 与持牌方合作

### 6.4 与数据指数业务联动

- 钢材物流真实运费数据 → CSP 价格指数（运费成本部分）
- 物流时效数据 → 钢材库存周转指数
- 路径数据 → 行业物流效率指数

## 七、合规与风控

### 7.1 资质要求

| 资质 | 必须 / 可选 | 说明 |
|---|---|---|
| 网络货运牌照 | 长期建议申请（M18+） | 让平台可正式开运输服务费发票 |
| 道路运输经营许可 | 不必须 | 我们不直接运营 |
| 第三方支付牌照 | 通过合作 | 担保资金走持牌支付 |
| 保险代理 | 与保险公司合作 | 不自营 |

### 7.2 风控关键点

| 风险 | 应对 |
|---|---|
| 司机失联/卷货 | 司机准入审核 + 保证金 + 保险兜底 |
| 货物损坏 | 强制保险 + 24h 客服介入 |
| 运费纠纷 | 平台担保结算 + 仲裁 SOP |
| 假单刷单 | 异常订单监控 + 风控引擎 |
