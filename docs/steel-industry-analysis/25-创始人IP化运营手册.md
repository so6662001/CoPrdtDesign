# 创始人 IP 化运营手册（视频号 / 公众号 / 抖音内容矩阵）

> 本文是 12 / 14 / 24 号文档的运营配套。把"创始人 IP 化"从一个口号落地为可执行的 3 平台内容矩阵，含定位、人设、内容方向、节奏、脚本模板、数据指标。
>
> 适用读者：CEO 本人 / CCO 首席内容官 / 内容运营团队 / PR 团队。
>
> **核心论点**：钢贸老板的获取信息渠道高度集中在**微信（公众号 + 视频号）+ 抖音**，且对"懂行的真人 IP" 有强烈信任。**创始人 IP 化是 0 成本最大获客渠道，3 年内可涨粉 100 万 +**，比任何投放都划算。

---

## 一、为什么必须做创始人 IP

### 1.1 钢贸老板的"信息消费习惯"（来自客户访谈）

| 渠道 | 日均时长 | 信任度 |
|---|---|---|
| 微信群刷消息 | 2-3 小时 | 中（真假信息混杂） |
| 公众号阅读 | 30 分钟 | 中高（深度内容） |
| 视频号刷短视频 | 30-60 分钟 | 高（人格化推荐） |
| 抖音刷短视频 | 30-60 分钟 | 中（娱乐为主） |
| 知乎/小红书 | <10 分钟 | 低（不是钢贸主战场） |
| 行业大会 | 1-2 次/年 | 极高（线下接触） |

**关键洞察**：
- **微信生态**（公众号 + 视频号 + 群）是钢贸老板的"工作时间主战场"
- **抖音**是"通勤+饭后娱乐时间"
- 公众号深度内容 + 视频号短视频 + 抖音获客的"组合拳"是最优解

### 1.2 创始人 IP 的 5 大核心价值

| 价值 | 说明 |
|---|---|
| **0 成本获客** | 内容做对了，每月 1-3 万自然涨粉 |
| **拉高客单价** | "我跟创始人聊过"= 客户更愿意付高价 |
| **吸引人才** | 高管/优秀员工通过 IP 主动来投 |
| **品牌资产** | 是公司最大的"无形资产"之一 |
| **政策友好** | 行业 KOL 更容易与监管/协会建立联系 |

### 1.3 不做 IP 的代价

- 同行竞争时缺乏差异化记忆点
- 销售成本增加 30%+（没有信任前置）
- 招聘高端人才更难
- 融资讲故事缺少"个人 IP 证据"

> **结论**：**创始人 IP 化不是"是否做"的选择，是"怎么做好"的选择。**

## 二、定位与人设设计

### 2.1 一句话定位

> **"钢贸老板的数字化导师 / 钢贸圈最懂数字化和数据的实战派创业者"**

### 2.2 人设三件套（个性 + 专业 + 温度）

| 维度 | 设定 |
|---|---|
| **人设核心** | 实战派 + 数据控 + 钢贸老司机 |
| **形象关键词** | 真诚 / 接地气 / 有数据 / 敢说真话 |
| **不要做** | 鸡汤大师 / 企业家秀 / 高大上专家 |
| **要做** | 帮钢贸老板解决具体问题的"懂技术的圈内人" |

### 2.3 标签矩阵（用于内容输出）

```
[创始人 IP 名称：建议用本名 + 一个标签]
例：王某某·钢贸数字化

主标签：
- 钢贸数字化创业者
- 服务 2000+ 钢贸企业 ERP 用户
- 钢铁产业互联网研究者

副标签：
- 95 后/85 后/70 后（看实际）
- 上海/杭州/北京（看实际）
- IT 出身/钢贸出身/行业老兵（看背景）

核心金句（贯穿所有内容）：
"让 2000 家钢贸老板少走弯路"
"用数据说话，不讲虚的"
"我做这件事，就是想把钢贸圈的痛点真正解决了"
```

### 2.4 视觉规范

| 元素 | 规范 |
|---|---|
| **头像** | 半身照，简洁背景，自然微笑（同一张用于所有平台） |
| **背景** | 办公室/工厂/钢贸现场（真实场景，不要摄影棚） |
| **着装** | 商务休闲（POLO 衫 / 深色休闲西装），**不要正式西装**（钢贸老板反感） |
| **表情** | 真诚 + 略带笑意，不浮夸 |
| **色调** | 蓝 + 灰（沉稳）+ 一抹橙（活力） |

### 2.5 反面教材（绝对不要做）

| 反面 | 例子 |
|---|---|
| 鸡汤洗脑 | "成功只需要努力" / "不抱怨的世界" |
| 装大师 | "10 个亿的项目，我是这么干的" |
| 浮夸炫富 | 豪车 / 名表 / 出国 |
| 刻意人设 | 假装年轻 / 假装老成 |
| 攻击同行 | 直接黑钢银/找钢网 |

## 三、3 平台内容矩阵设计

### 3.1 平台分工

| 平台 | 主要功能 | 内容形态 | 频率 |
|---|---|---|---|
| **公众号** | 深度内容沉淀 + 转化 | 长图文 1500-3000 字 | 周 2 篇 |
| **视频号** | 微信生态获客 + IP 强化 | 1-3 分钟短视频 | 日更 1-2 条 |
| **抖音** | 大众触达 + 行业渗透 | 30 秒-1 分钟 | 日更 1-2 条 |
| **小程序/APP** | 流量沉淀转化 | 钢链通工具 | 持续 |

### 3.2 视频号优先（钢贸老板主战场）

视频号在三个平台中**优先级最高**，原因：
- 微信生态嵌入，钢贸老板"工作中刷"
- 算法 + 社交推荐双驱动
- 视频号关联公众号引流流畅
- 视频号关联企业微信和小程序，转化路径短

## 四、6 大内容栏目（横跨 3 平台）

### 4.1 内容栏目矩阵

| 栏目 | 内容方向 | 平台 | 频率 |
|---|---|---|---|
| **栏目 A：钢市行情解读** | 每日钢价 + AI 解读 + 我的判断 | 全平台 | 每日 1 |
| **栏目 B：钢贸老板真实故事** | 拜访客户 + 客户故事 + 行业故事 | 视频号 + 抖音 | 周 2-3 |
| **栏目 C：钢贸数字化干货** | 数字化经验 / 工具教程 / 数据洞察 | 公众号 + 视频号 | 周 2-3 |
| **栏目 D：钢贸老板避坑指南** | 风控 / 合同 / 财务陷阱 | 全平台 | 周 1-2 |
| **栏目 E：行业研究与思考** | 钢铁产业互联网 / 行业大势 | 公众号 | 周 1 |
| **栏目 F：创业者日记** | 个人成长 / 创业心得 / 团队故事 | 视频号 + 抖音 | 周 1-2 |

### 4.2 栏目 A：钢市行情解读（最高频）

#### 内容形式

```
【公众号】每日早报 (7:00 推送)
  - 标题: 4月27日钢市观察:螺纹高位震荡, 库存压力来了
  - 内容: 1500-2000 字
    - 关键价格变化
    - 影响因素分析
    - 我的观点
    - 行动建议
    - "[基于平台 2000 家真实数据]" 独家洞察

【视频号】每日早报短视频 (8:00 推送)
  - 时长: 1-2 分钟
  - 形式: 创始人对镜头讲解
  - 脚本模板见下

【抖音】每日早报短视频 (8:30 推送)
  - 同视频号内容, 适配抖音节奏 (前 3 秒钩子)
```

#### 视频号脚本模板（钢市早报）

```
【开头钩子 - 5 秒】
今天螺纹钢现货突然涨了 30 块, 你知道为什么吗?
（手势 + 直视镜头）

【内容主体 - 60 秒】
我是 [姓名], 服务过 2000 家钢贸老板的数字化创业者。

今天有三件事你必须知道:
第一,沙钢出厂价上调 50,带动整个华东市场情绪转好
第二,我们平台数据显示,昨天华东出货量比上周同期增加 12%
第三,但是江苏地区库存仍然在 12 个月高位 ⚠️

【结论 + 行动建议 - 20 秒】
我的判断是, 短期偏强, 但库存压力没消化, 不要追高

如果你是采购方, 现在不是补货的时候, 等回调
如果你是贸易商, 这波情绪可以高位出 1/3 货

【结尾 CTA - 5 秒】
关注我, 每天早 8 点钢市观察
评论区说说, 你今天打算怎么操作?
```

### 4.3 栏目 B：钢贸老板真实故事（高黏性）

#### 内容形式

每周拜访 1-2 家钢贸老板，把"对话"变成内容：

```
【视频号】"老板,你这年是怎么过的?" 系列
  - 时长: 3-5 分钟
  - 形式: 创始人 + 钢贸老板对话
  - 内容: 真实的痛点、决策、成败、复盘

【抖音】精剪 30 秒版本 + 引流公众号深度版
```

#### 拍摄 SOP

```
1. 提前预约 (与老板沟通拍摄目的, 强调正面/中性, 不黑)
2. 准备 10 个问题 (真痛点, 不是商业互吹)
3. 自然光, 现场环境 (办公室/仓库/工地)
4. 1 个摄像师 + 1 个收音
5. 时长 30-60 分钟拍, 剪到 3-5 分钟
6. 老板审核(默认通过, 拒绝就不发)
7. 发布后给老板回赠"上墙合影"或"推广券"
```

#### 选题建议

- "经营了 20 年, 第一次想转型, 我做了这件事"
- "去年亏了 800 万, 我现在悟出了什么道理"
- "钢贸老板的一天: 凌晨 5 点起床后做了什么"
- "我老婆/孩子如何看我做这行"
- "如果让你重新选择, 你还会做钢贸吗?"

### 4.4 栏目 C：钢贸数字化干货（最大转化）

#### 内容形式

```
【公众号】2000-3000 字深度文章
  - 标题: "20 年钢贸老板第一次用 AI 报价, 月省 8 万"
  - 结构:
    - 钩子: 真实案例
    - 痛点: 老板原来怎么做
    - 转折: 用了什么方法/工具
    - 数据: 量化效果
    - 通用方法: 你也能这么做
    - CTA: 关注/试用钢链通

【视频号】3 分钟教程视频
  - 屏幕录制 + 旁白
  - 一个具体功能/方法
```

#### 选题清单（提前准备 50 个）

```
1. 用 Excel 管理库存的 5 个致命错误
2. 业务员私单飞单, 老板怎么发现?
3. 月底对账总扯皮?试试这个 H5 工具
4. 客户欠 500 万跑路, 早知道就该这么查信用
5. 钢贸财务月底加班 5 天, 一招省到 1 天
6. 用 AI 报价, 我团队效率提升 50%
7. 仓库账实差 100 吨, 怎么快速找到原因?
8. 票据贴现, 怎么省下 30% 利息?
9. 钢厂代理任务月底差 800 吨, 怎么办?
10. 司机偷拉/装错货, 怎么用扫码彻底杜绝?
... (每周补充 1 个)
```

### 4.5 栏目 D：钢贸老板避坑指南（高传播）

#### 内容方向

把行业里"老板们踩过的坑"系统化，做成可传播的避坑内容：

```
【经典选题】
- "5 种业务员一定不能用的合同条款"
- "客户给你这种承兑, 千万别收"
- "钢厂这 3 种代理协议, 看着好其实是坑"
- "工地客户欠款, 怎么定性催收 80% 能拿回?"
- "金税四期下, 钢贸进项发票要这样收"
- "调货公司常见骗局 Top 10"
- "仓库管理员这 5 个动作, 是飞单前兆"
```

#### 表现形式

```
【视频号】"血泪教训" 系列, 1-2 分钟
  - 钩子: "我有个客户去年因为这事亏了 200 万"
  - 案例: 具体故事
  - 总结: 3 个 takeaway

【公众号】"避坑大全" 长文, 2000+ 字, 配真实案例
```

### 4.6 栏目 E：行业研究与思考（深度，公众号专属）

#### 内容方向

```
- "中国钢贸产业互联网 14 年: 钢银/找钢网为什么都没赢?"
- "钢贸数字化的 3 大趋势: 数据 / AI / 集采"
- "钢贸老板, 数字化这 3 个错你别再犯"
- "为什么钢贸 ERP 大多失败?(以 2000 家深度用户为案例)"
- "钢贸的下一个十年: 我的 5 个判断"
- "数据资产入表对钢贸行业意味着什么?"
```

#### 频率

每周 1 篇，2500-4000 字深度长文。**这是建立"行业 thought leader"的关键栏目**。

### 4.7 栏目 F：创业者日记（人格化）

#### 内容方向

```
- "今年最难的一个月: 团队 5 个核心走了 3 个"
- "和投资人谈崩了, 我做错了什么"
- "我妈不理解我做的事"
- "我团队加班到凌晨 2 点, 我心里很难受"
- "刚跟一个老板聊完, 突然想哭"
- "今年我犯过最大的错"
```

#### 表现形式

```
【视频号】3-5 分钟真情流露
  - 不要剧本, 真实表达
  - 不要背景音乐过度煽情
  - 适当展示创业的不易, 但不卖惨
```

#### 注意事项

- **频率不能太高**（每周 1 次足够），否则成"鸡汤创业秀"
- **必须真实**，不要为了情绪而编故事
- **适度暴露脆弱**，但不能影响商业判断的可信度

## 六、爆款打造方法论

### 6.1 爆款公式

```
爆款 = 真实 × 干货 × 钩子 × 时机 × 一点情绪

真实: 真实数据 + 真实案例 + 真实表达
干货: 看完有收获, 能解决问题
钩子: 前 3 秒抓住注意力
时机: 蹭热点 / 行业大事 / 政策
情绪: 共鸣 / 愤怒 / 反差
```

### 6.2 标题模板（已验证）

```
1. "20 年钢贸老板第一次用 AI 报价, 月省 8 万"
   (真实人物 + 数据 + 反差)

2. "你以为是同行,其实他在用平台数据偷你客户"
   (痛点 + 反转)

3. "我服务的 2000 家钢贸,每年加起来亏 50 个亿"
   (大数据 + 强冲击)

4. "钢厂出厂涨 50, 钢贸老板说: '我赚不到钱了'"
   (热点 + 真实声音)

5. "如果让我重新做钢贸, 我一定不会做这 3 件事"
   (反思 + 干货)

6. "为什么找钢网/钢银都'失败'了?这是我的看法"
   (热点 + 个人观点)

7. "我跟央行的人聊完, 钢贸数据原来这么值钱"
   (权威 + 反差)

8. "凌晨 3 点接到客户电话, 我第一次掉眼泪"
   (情感 + 故事)
```

### 6.3 视频号 / 抖音前 3 秒"开场钩子"模板

```
模板 A: 数据冲击
  "今年钢贸圈坏账已经超过 30 亿"

模板 B: 反转开场
  "你觉得钢贸不赚钱? 那是你不会做"

模板 C: 提问
  "为什么 90% 的钢贸老板算不清自己赚多少?"

模板 D: 故事
  "凌晨 5 点, 张老板的电话又响了"

模板 E: 直接答案
  "钢贸最赚钱的 3 件事, 我给你说完"

模板 F: 痛点
  "你这家客户欠了 200 万, 你知道他在多少同行处也欠款吗?"
```

## 七、内容运营团队配置

### 7.1 团队组成（M3-M6 起步）

| 角色 | 人数 | 职责 |
|---|---|---|
| **首席内容官 CCO** | 1 | 内容战略 / 节奏把控 / 品牌守护 |
| **创始人 IP 经纪人** | 1 | 创始人内容拍摄 / 排期 / 反馈 |
| **行情分析师** | 2 | 每日早报内容产出 |
| **视频号编辑** | 2 | 视频拍摄 / 剪辑 / 发布 |
| **公众号编辑** | 1 | 长图文写作 / 排版 |
| **抖音编辑** | 1 | 抖音内容适配 / 数据分析 |
| **直播运营**（M6+） | 1 | 创始人直播 / 客户访谈直播 |

**M3 起步配置**：CCO + 经纪人 + 2 个分析师 + 2 个编辑 = **6 人**

### 7.2 创始人投入时间

## 十一、风险与应对

## 十二、创始人 IP 化的"心理建设"

### 12.1 创始人必须想明白的 3 件事

#### 第一件事：**面子和涨粉哪个更重要？**

- 创始人 IP 化必然意味着"被别人议论"
- 必须做好心理建设：不要怕负面评论
- 评论越多 = 流量越大 = 价值越高

#### 第二件事：**真实和包装哪个更重要？**

- 真实永远赢
- 创始人 IP 不是装出来的, 是"演化"出来的
- 不要 fake, 钢贸老板眼睛雪亮

#### 第三件事：**短期和长期哪个更重要？**

- IP 是 3-5 年的事, 不是 3 个月的事
- 前 6 个月要忍受"涨粉慢、变现慢"
- 第 12 个月开始指数级增长

### 12.2 5 条创始人内容工作的"底线"

1. **不夸大自己**（用户都不傻）
2. **不抹黑同行**（行业小，得罪不起）
3. **不发未审核的数据**（合规第一）
4. **不在情绪化时发内容**（48 小时冷静期）
5. **不为了热点而牺牲专业**（坚守"钢贸数字化"领域）
