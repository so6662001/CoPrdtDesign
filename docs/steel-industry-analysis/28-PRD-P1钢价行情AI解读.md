# PRD — P1 钢价行情 + AI 解读

> 第 1 个 SaaS 标品的完整产品需求文档 + UI 设计草图（文字描述 + ASCII 线框）。
>
> **战略定位**：信息钩，让钢贸老板每天打开 1+ 次。是飞轮的拉新引擎。
>
> 适用读者：产品经理、研发、UI/UX、内容运营。

---

## 一、产品概述

### 1.1 一句话介绍
> 早上 7:00 醒来打开手机就能看到的"钢市观察+AI 解读+独家数据"。

### 1.2 核心价值
- **比微信群快**：早 7:00 全网最早推送
- **比钢联准**：基于平台 2,000+ 真实成交数据
- **比专家懂**：AI 解读 + 个性化建议

### 1.3 用户场景
- 老板早 7:00 起床，刷手机看行情（高频）
- 业务员上班前看行情（决定今日报价基调）
- 采购员决定是否补货
- 工地包工头决定何时拿货

### 1.4 业务目标（M3）

| 指标 | 目标 |
|---|---|
| DAU | ≥ 5,000 |
| 公众号粉丝 | ≥ 5w |
| 视频号粉丝 | ≥ 10w |
| 早 7 点推送打开率 | ≥ 35% |
| 付费订阅转化率（999/年） | ≥ 1% |

## 二、用户角色与权限

| 角色 | 看到 | 限制 |
|---|---|---|
| **未登录访客** | 行情主页（脱敏）+ 注册引导 | 不能订阅 / 看历史 / 看个性化 |
| **免费注册用户** | 早晚两次推送 + 基础解读 + 30 天历史曲线 | 不可看深度解读 / 5 年历史 |
| **付费用户**（999/年） | + AI 深度解读 + 5 年历史 + 自定义订阅 + 周报 + 闭门会预约 | — |
| **企业版用户** | + 行情 API + 团队多账号 + 数据导出 + 无广告 | — |

## 四、核心功能详细设计

### 4.1 功能 F1-001：每日行情早报推送（核心 MVP）

#### 业务流程
```
06:00  数据中台采集前一日真实成交 + 当日开盘外部行情
06:30  AI 自动生成早报草稿
06:30-06:50  内容编辑审核（10 min 内）
06:50  正式推送
```

#### 推送渠道与节奏
| 渠道 | 时间 | 形式 |
|---|---|---|
| APP / 小程序 | 06:50 | 内推（红点 + Banner） |
| 公众号 | 07:00 | 图文消息（强制推送，付费用户优先） |
| 视频号 | 07:30 | 1-2 min 短视频（创始人 IP） |
| 抖音 | 08:00 | 30s 适配版 |
| 企微机器人 | 07:00 | 群发（订阅企微的企业用户） |
| 短信 | — | 仅付费用户重大变化（涨跌 > 50） |

#### 早报结构
```
【一句话总结】
螺纹小幅上涨，板材偏强，市场情绪转好

【关键价格】
- 螺纹钢上海现货：4,150 (+20)
- 螺纹钢期货 RB2510：3,920 (+15)
- 热卷上海现货：4,280 (+30)
- 板材华东：4,120 (+10)

【影响因素】
✅ 利好：唐山限产消息发酵 / 工地节后复工集中
❌ 利空：库存仍处于 12 个月高位
⚠️ 关注：央行 LPR 周三公布

【AI 建议】
- 短期：偏强但库存压力大，建议高位逢高出货
- 中期：等政策落地再决定
- 长材采购方：可考虑分批补货

【独家数据】
（基于平台 2000+ 钢贸商真实数据）
- 华东出货量较昨日 +12%
- 江苏地区库存仍处于 12 个月高位
- 钢贸商持仓信心指数：62（偏乐观）

【相关：钢市观察短视频】 [视频号链接]
```

### 4.2 功能 F1-002：综合指数 CSP-V0 展示

#### 设计要点
- 首页顶部大字号显示
- 实时更新（5 min）
- 颜色：上涨红 / 下跌绿
- 点击进入指数详情（成分品种、计算口径、历史走势）
- 标注"基于平台真实成交，涵盖品种/钢厂/区域"

### 4.3 功能 F1-003：我的关注（个性化）

#### 业务规则
- 注册时引导用户选择主营品类（板/管/型/线）+ 区域
- 用户可后续自定义关注（最多 20 个 sku × region）
- 首页"我的关注"卡片优先显示
- 涨跌阈值告警（涨跌 > X 元，微信推送）

### 4.4 功能 F1-004：品种行情详情

#### 必须展示
- 实时价格 + 涨跌幅
- 历史曲线（30 天 / 90 天 / 1 年 / 5 年）
- 同品种区域对比（华东/华北/华南/...）
- 钢厂出厂价对比
- 期货 vs 现货价差
- 该品种 AI 解读
- 历史成交量
- "我的关注" / "取消关注"

### 4.5 功能 F1-005：AI 解读引擎

#### 模型选型
- 主：通义千问 / 文心一言 / GPT-4 / Claude（多模型组合）
- 辅：自有模型（基于钢贸语料微调）

#### 输入数据
- 实时行情（CSP-V0 + 子指数 + 期货）
- 平台真实成交数据
- 政策/钢厂/经济新闻（外部数据）
- 历史模式（昨日/上周/上月/同比）

#### 输出结构
```json
{
  "summary": "一句话总结",
  "key_prices": [...],
  "factors": {
    "bullish": [...],
    "bearish": [...],
    "watch": [...]
  },
  "ai_advice": {
    "short_term": "...",
    "mid_term": "...",
    "for_buyer": "...",
    "for_seller": "..."
  },
  "proprietary_data": [...]
}
```

#### 编辑审核
- 内容运营 10 min 内审核
- 可修改 / 退回 / 强发
- 审核通过后正式推送

### 4.6 功能 F1-006：创始人 IP 频道

#### 内容栏目（与 25 号文档对齐）
- 钢市观察（每日，置顶）
- 钢贸老板真实故事（周 2-3）
- 钢贸数字化干货（周 2-3）
- 钢贸老板避坑指南（周 1-2）
- 行业研究与思考（周 1）
- 创业者日记（周 1-2）

#### 视频号引流
- 频道首页嵌入视频号 H5 播放
- 关注公众号 + 视频号双引导

## 六、数据模型（节选关键）

```
PriceQuote (实时行情)
  - id / sku_id / region / source(钢联/Mysteel/平台真实)
  - quote_price / quote_time / quote_type(现货/期货/出厂)

DailyReport (早报)
  - id / report_date / type(早/晚)
  - title / summary / ai_analysis_json
  - key_prices_json / factors_json
  - editor_id / published_at / status

UserSubscription (订阅设置)
  - user_id / sku_filters / region_filters
  - threshold_change / push_channels[]
  - push_times[] / is_paid

UserBehaviorLog (行为)
  - user_id / content_id
  - read_duration / share_count / like

ProprietaryDataPoint (独家数据)
  - data_date / sku_id / region
  - real_transaction_volume / real_avg_price
  - inventory_level / confidence_score

CSPIndex (CSP-V0)
  - level(master/sub) / sub_type
  - region / date / value / change
  - components_json
```
