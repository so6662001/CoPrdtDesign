# PRD — P4 AI 报价助手

> 第 4 个 SaaS 标品的完整 PRD + UI 设计。
>
> **战略定位**：业务员每天 50+ 次的核心场景，是平台日活的发动机。同时承担"业务员行为风控"和"AI 单一报价（替代多家比价）"两个关键战略目标。

---

## 一、产品概述

### 1.1 一句话
> 业务员对手机说一句"客户 A 要 30 吨 Φ16"，AI 0.5 秒给出 4 个数字 + 1 个建议价 + 锁价单 H5——比电话报价快 50 倍。

### 1.2 核心价值
- **业务员**：报价从 5 分钟到 5 秒
- **老板**：所有报价留痕，业务员私单飞单无处遁形
- **客户**：收到正规报价单，可在线锁价/还价/确认下单
- **平台**：所有报价数据进入数据中台

### 1.3 业务目标（M3）

| 指标 | 目标 |
|---|---|
| 业务员激活率 | ≥ 70% |
| 月报价单数 | ≥ 5w 张 |
| 业务员日均报价 | ≥ 5 次 |
| 报价 → 成交转化率 | ≥ 20% |
| 异常报价识别率 | ≥ 90% |

## 二、用户角色

| 角色 | 操作 |
|---|---|
| **业务员（SALES）** | 一键报价 / 历史报价 / 客户画像 |
| **老板（OWNER）** | 报价审批 / 异常预警 / 业务员行为分析 |
| **客户（CLIENT，外部）** | 收报价单 H5 / 锁价 / 确认/还价 |
| **财务（FIN）** | 成交后自动生成合同 / 入账 |
| **客户成功（CS）** | 报价转化分析 / 帮业务员跟单 |

## 四、核心功能详细设计

### 4.1 F4-001 一键报价（核心）

#### 业务流程
```
[业务员手机点"一键报价"]
    └─ 输入需求（3 种方式）：
        - 语音：说"给客户 A 报 Φ16 螺纹 30 吨"
        - 文字：选客户 + 选规格 + 输入数量
        - 历史：从客户历史询价直接复制
    └─ AI 0.5 秒返回 4 个数字 + 1 个建议价（详见 4.2）
    └─ 业务员选择价格（建议价 / 自定义）
    └─ 选择有效期（30 分钟 / 1 小时 / 1 天）
    └─ 生成报价单 H5
    └─ 一键转发微信给客户
    └─ 客户在 H5 操作（详见 4.4）
```

#### 输入识别
- 语音识别 → NLP 解析 → 结构化（客户/规格/数量/区域）
- 客户名模糊匹配（"老张"→ 张三 钢贸 / 张氏建材...）
- 规格模糊匹配（"螺纹 16"→ HRB400E Φ16）
- 失败时 → 引导一步步选

### 4.2 F4-002 AI 4 数字 + 建议价（关键）

#### 4 个必显数字（强制）
```
1. 加权移动成本: 4090 元/吨
   （该规格的平均库存成本，含运费）

2. 最近 7 天最低成交价: 4120 元/吨
   （平台真实成交数据，提示底线）

3. 该客户历史均价: 4180 元/吨
   （这个客户过去对该规格的成交均价）

4. 当前市场基准价: 4150 元/吨
   （CSP-V0 实时指数）
```

#### 建议价计算
```
建议价区间 = (max(成本+合理毛利, 7天最低), 客户历史均价)

例如:
  成本 4090 + 合理毛利 50 = 4140
  7 天最低 = 4120
  → 下限 = 4140
  
  客户历史均价 = 4180
  → 上限 = 4180
  
  建议价区间: 4140 - 4180
  推荐价: 4170 (建议毛利 80/吨)
```

#### 风险提示
```
- 业务员要报 4080 → 红字: ⚠️ 低于成本 10/吨, 需要老板审批
- 业务员要报 4100 → 黄字: ⚠️ 低于合理毛利, 触发审批
- 业务员要报 4250 → 红字: ⚠️ 高于客户历史均价 70/吨, 客户可能拒绝
```

### 4.3 F4-003 老板审批流（关键风控）

#### 触发条件
```
触发审批的情况:
  1. 报价 < 成本 + 5 元/吨（亏损）
  2. 报价 < 客户历史均价 - 5%（异常压价）
  3. 报价 > 当前市场价 + 5%（异常加价）
  4. 报价金额 > 100 万（大单）
  5. 业务员异常评分 > 60（私单/飞单嫌疑）

不触发审批:
  - 报价在合理区间内 → 业务员直接发出
```

#### 审批流程
```
[业务员发起报价] → 系统判断需要审批
    └─ 推送给老板（手机 + 企微）
        └─ 老板看到 4 个数字 + 业务员说明 + 客户历史
            └─ 老板点 [准 / 驳 / 改]
                ├─ 准 → 报价单生效，发给客户
                ├─ 驳 → 业务员重新报价
                └─ 改 → 老板修改价格 → 直接发给客户
```

#### 审批 SLA
- 老板 30 min 内必须响应（系统自动催促）
- 30 min 未响应 → 推送给副总
- 60 min 未响应 → 业务员自动撤回，抱歉客户

### 4.5 F4-005 业务员行为风控

#### 监控维度
```
业务员每个报价 + 成交都进入风控引擎:

1. 毛利偏离度
   - 业务员平均毛利 vs 团队平均毛利
   - 持续偏低 → 怀疑私单

2. 客户集中度
   - 业务员的销量是否集中在 1-2 家客户
   - 集中度突然上升 → 怀疑

3. 报价异常
   - 给某客户报价持续低于市场
   - 报价后未成交但客户后续有提货 → 怀疑账外交易

4. 客户付款异常
   - 该业务员客户的付款评分整体偏低
   - 多家客户欠款 → 怀疑

5. 离职信号
   - 客户突然不回信息
   - 客户在其他业务员处有交易
   - 业务员频繁请假/外出
```

#### 风控评分
```
业务员风控评分 (0-100):
  - 0-30: 高风险 (老板必查)
  - 30-60: 中风险 (定期 review)
  - 60-100: 正常

每月推送给老板:
  - Top 10 高风险业务员
  - 异常报价 Top 10
  - 客户流失预警
```

### 4.7 F4-007 二级匿名比价（可选）

> 默认是 AI 单一报价（一对一）。如果客户执意要比价，进入"二级入口"。

```
[客户在 H5 点"我要看更多卖家"]
    → 弹窗确认: "是否扩大查询范围? 这可能影响您与当前卖家的合作"
    → 客户确认 → 进入"匿名比价"模式

匿名比价模式:
  - 显示 3 家卖家（卖家 A/B/C，匿名）
  - 报价分时段错峰显示（不实时竞价）
  - 卖家不知道自己被比价（事后才知道）
  - 客户选定后，平台才告诉双方身份

注意:
  - 此模式默认关闭
  - 必须客户主动选择
  - 一次成交后, 客户主权 6 个月生效
```

### 4.8 F4-008 报价数据沉淀（数据中台）

```
每个报价/成交事件流入数据中台:
  - QuoteRequested
  - QuoteGenerated
  - QuoteSentToClient
  - QuoteAcceptedByClient
  - QuoteAnomalyDetected

用途:
  - CSP-V0 真实成交价指数
  - 客户付款行为评分
  - 业务员行为画像
  - 老板看板
  - 报价转化漏斗分析
```

## 六、数据模型

```
QuoteRequest (报价请求)
  - id / sales_id / client_id / sku_id / quantity
  - input_method (voice/text/template)
  - requested_at

QuoteSuggestion (AI 建议)
  - request_id / weighted_cost / recent_low_price
  - client_avg_price / market_price
  - suggested_price_range / suggested_margin

Quote (报价单)
  - id / request_id / actual_price
  - lock_until / status
  - approval_required / approval_status / approver_id
  - sent_to_client_at / accepted_at / rejected_at

QuoteApproval (审批)
  - quote_id / requested_at / approver_id
  - decision / decision_at / new_price (改的话)

ClientProfile (客户画像)
  - client_id / payment_score / risk_level
  - dealing_freq / avg_account_period / preferred_mills

SalesBehaviorScore (业务员风控)
  - sales_id / period
  - margin_deviation / client_concentration
  - anomaly_count / risk_score
```

## 七、与其他模块的联动

| 联动 | 数据流 |
|---|---|
| **数据中台** | 调用实时行情 + 客户画像 + 客户均价 |
| **P3 扫码出库** | 报价成交 → 自动派出库单 |
| **P5 资金大盘** | 成交合同 → 应收预增 |
| **P2 对账单** | 历史成交 → 对账数据 |
| **风控** | 业务员行为评分 |
| **金融业务（M7+）** | 报价数据 → 信用模型输入 |
