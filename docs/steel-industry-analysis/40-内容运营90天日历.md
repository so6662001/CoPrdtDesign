# 内容运营 90 天日历

> 本文是 25 / 28 / 33 / 38 号文档的执行细化。MVP 启动后 90 天的内容运营具体计划——每天/每周/每月发什么内容、谁负责、目标是什么。
>
> 适用读者：CCO 首席内容官 / 创始人 / 内容运营团队 / 销售。
>
> **核心目标**：
> - M1 末：公众号粉 1w / 视频号粉 2w / 抖音粉 1w
> - M2 末：公众号粉 3w / 视频号粉 6w / 抖音粉 3w

## 十四、内容审核 SOP

### 14.1 三级审核

```
L1: 内容编辑自审 (写作时)
L2: CCO 审核 (发布前)
L3: 法务审核 (敏感内容)

敏感内容 (必须 L3):
  - 涉及具体公司负面 (老赖榜)
  - 涉及监管 / 政府 / 政策
  - 涉及金融 / 数据合规
  - 涉及大客户 / KOL 合作
```

### 14.2 危机预案

```
24 小时内出现负面舆情:
  1. CCO + CEO + 法务紧急会议
  2. 内容立即下架（如果失实）
  3. 公开道歉 (如果属实)
  4. 跟进改进 (公开)

内容翻车:
  1. 1 小时内删除
  2. 内部复盘
  3. 团队培训
```

## 十八、最终结论

> **内容运营 90 天的核心目标不是"涨粉"，是"建立品牌信任 + 拉新 + 案例资产"。**
>
> **3 个月后, 钢贸圈应该认知到:**
> - 钢链通是行业最懂数字化的公司
> - 创始人是行业 KOL
> - 5 家种子客户案例铁证
> - 老赖榜代表行业立场
>
> **关键判断**:
> 1. CCO 必须是产业互联网内容老兵 (M1 必招)
> 2. 创始人每周 8-10 小时投入是必须的
> 3. 老赖榜首发是 90 天最大的 PR 事件
> 4. 案例是后续推广的"信任前置"
>
> **没有内容, 没有 IP; 没有 IP, 没有信任; 没有信任, 没有飞轮。**
