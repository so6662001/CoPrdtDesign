# PRD — P5 资金大盘 + 电子合同

> 第 5 个 SaaS 标品的完整 PRD + UI 设计。
>
> **战略定位**：老板每天打开 5+ 次的"钱包" + 月度合同管理 = 替代银行 APP 和纸质合同，是金融业务的入口。

---

## 一、产品概述

### 1.1 一句话
> 老板打开手机就看到"今天真正赚了多少钱、未来 30 天现金缺口、客户欠款风险"——5 个 APP 合并为 1 个大盘 + 所有合同电子签 + 一键金融操作。

### 1.2 核心价值
- **老板**：从打开 5 个 APP 到 1 个大盘
- **财务**：应收/票据/合同集中管理
- **业务员**：客户欠款一键查
- **金融业务（M7+）入口**：贴现/保理/采购融资按钮即触发

### 1.3 业务目标（M3-M6）

| 指标 | M3 | M6 |
|---|---|---|
| 老板日均打开次数 | 3 | 5 |
| 资金告警响应率 | 60% | 80% |
| 月生成电子合同数 | 1,000 | 5,000 |
| 票据池在线管理 | 2,000 张 | 10,000 张 |

## 四、核心功能详细设计

### 4.1 F5-001 真实净资产（核心）

#### 计算公式
```
真实净资产 = 现金 + 应收 + 库存浮盈 - 应付 - 浮亏

具体:
  现金 = 多银行卡聚合余额
  应收 = 全部应收账款 - 30% 风险准备金（按账龄）
  库存浮盈 = 库存量 × (实时市价 - 加权成本)
  应付 = 全部应付账款（即将到期）
  浮亏 = 票据贴现成本 + 资金占用成本

本月真实净利 = 本月毛利 - 本月费用 - 资金成本 - 浮盈变化
```

#### 显示规则
```
首页大字号:
  真实净资产: ¥ 1,033 万
    ↑ 较昨日 +5 万

本月真实净利: +18 万 ✅
  （扣除资金成本和库存浮亏）
```

### 4.5 F5-005 资金告警引擎

```
告警类型:
  1. 应收逾期: 客户 X 欠款超过授信 / 60 天未付
  2. 应付到期: 钢厂应付 5 天内到期, 现金不足
  3. 票据贴现机会: 这张票今天贴现可省 1,200 元
  4. 客户新增风险: 平台征信检测到客户新风险
  5. 集采任务: 本月差 800 吨, 错过返点 4 万
  6. 库存压库: Φ20 库存超 30 天周转

推送渠道:
  - APP / 小程序内推
  - 微信
  - 短信（重大告警）
```

### 4.9 F5-009 电子合同 - AI 生成 + 风险审查

#### AI 生成流程
```
[财务/业务员选"新建合同"]
    └─ 选模板 (代理/现货/调货/加工/集采)
        └─ 输入交易要素 (买卖方/规格/数量/价格/账期/...)
            └─ AI 自动生成合同条款
                └─ AI 风险审查 (高亮关键条款):
                    - 付款方式风险
                    - 违约金条款
                    - 计量方式
                    - 争议解决
                └─ 双方电子签章
                    - 接 e签宝 / 法大大
                    - 双方在 H5 完成
                └─ 自动归档 (按客户/规格/时间)
```

#### 关键合同字段（强校验）
- 计量方式（理计/过磅/取小/取大）—— 必须明确
- 质保书要求 —— 必须明确
- 货损归属 —— 必须明确
- 付款方式（现金/承兑/账期）—— 必须明确
- 违约金 —— 必须明确

#### 争议溯源
```
出现争议时:
  [合同] + [出库单] + [磅单] + [签收] + [对账单]
  → 一键提取所有相关证据
  → 生成 PDF 包
  → 用于诉讼/调解
```

## 六、数据模型

```
CashDashboard (实时计算视图)
  - tenant_id / snapshot_date
  - bank_balance_total / bank_breakdown_json
  - receivables_aging_json / payables_breakdown_json
  - notes_pool / notes_aging
  - inventory_floating_pl / real_net_asset / daily_change

Contract (合同)
  - id / tenant_id / contract_no / type
  - parties[] / total_amount
  - signed_at / sign_method
  - related_documents[] / status

Note (承兑票)
  - id / owner_tenant_id / face_amount / due_date
  - issuer_bank / credit_grade / status

Receivable (应收账款)
  - id / tenant_id / customer_id / amount / due_date
  - status / aging_bucket / overdue_days

Alert (告警)
  - tenant_id / type / severity
  - target_object / message
  - triggered_at / action_options[]
```
