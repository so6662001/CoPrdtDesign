### 1.2 与本业务相关的核心红线

| 红线 | 触线后果 |
|---|---|
| 未经授权处理用户数据 | 民事赔偿 + 行政处罚 + 刑事风险 |

## 二、6 大法律文本模板

### 2.1 文本 1：用户服务协议（钢链通服务协议）

#### 协议核心条款（精简版）

```
《钢链通用户服务协议》

[甲方：用户企业名称、统一社会信用代码、法定代表人]
[乙方：钢链通运营主体（公司名称、统一社会信用代码）]

第一章 服务内容
1.1 乙方为甲方提供以下服务：
    (1) 钢贸 SaaS 工具（含电子对账单、扫码出库、AI 报价、资金大盘、电子合同、行情资讯）
    (2) 钢贸社区与内容服务
    (3) 集采、物流、金融分润、保险等增值服务
    (4) 数据指数与风险预警服务
    
1.2 服务的具体内容、版本与价格以乙方在平台公布的为准。

第二章 用户权利与义务
2.1 甲方有权：
    (1) 按所购套餐使用平台服务
    (2) 随时退订（剩余服务期按比例退还）
    (3) 撤回数据贡献授权（详见数据贡献条款）
    (4) 申请数据删除（除法律法规要求保留外）

2.2 甲方义务：
    (1) 提供真实、准确、合法的注册信息
    (2) 妥善保管账号与密码
    (3) 不得利用平台从事违法犯罪行为
    (4) 不得恶意攻击、破坏平台
    (5) 不得在平台传播违法、欺诈信息

第三章 乙方权利与义务
3.1 乙方有权：
    (1) 制定与调整服务规则、价格
    (2) 对违规行为采取限制、暂停、终止服务等措施
    (3) 处理用户业务过程中产生的数据（详见隐私政策与数据贡献条款）

3.2 乙方义务：
    (1) 保障平台正常运行
    (2) 保护用户数据安全
    (3) 按法律规定开展业务
    (4) 提供技术支持与客户服务

第四章 费用与支付
4.1 服务费用以乙方在平台公示的价格为准。
4.2 甲方按所选套餐支付费用。
4.3 退款、退订规则详见 [退款规则附件]。

第五章 知识产权
5.1 平台软件、文档、内容的知识产权归乙方所有。
5.2 甲方在平台产生的数据，所有权归甲方，乙方在本协议授权范围内享有处理使用权。
5.3 甲方对平台用户名、企业资料、自定义内容拥有所有权，但授权乙方在服务过程中使用。

第六章 数据条款（核心，详见附件）
6.1 个人信息处理：详见《钢链通隐私政策》
6.2 企业数据贡献：详见《钢链通数据贡献授权条款》
6.3 数据安全：乙方采取等保 2 级以上安全措施
6.4 数据删除：甲方注销后 30 日内删除（法律要求保留除外）

第七章 服务终止
7.1 甲方可随时终止服务（按剩余天数退款）
7.2 甲方违反本协议且整改无效时，乙方可终止服务
7.3 不可抗力时双方均可终止

第八章 责任限制
8.1 乙方对甲方的责任以甲方支付的最近 12 个月服务费为限
8.2 不承担间接损失、利润损失等
8.3 因甲方违法行为造成的损失由甲方自行承担

第九章 争议解决
9.1 适用中华人民共和国法律
9.2 争议先协商；协商不成提交 [乙方所在地] 人民法院诉讼

第十章 其他
10.1 本协议自甲方点击"我同意"或开始使用服务之日起生效
10.2 本协议由乙方根据法律变化随时更新（重大变更提前 30 日公告）
10.3 本协议附件具有同等法律效力

附件：
A. 隐私政策
B. 数据贡献授权条款
C. 服务等级承诺（SLA）
D. 退款规则
E. 风险提示书

[甲方签章 / 乙方签章]
[日期]
```

### 2.2 文本 2：隐私政策

#### 隐私政策核心条款

```
《钢链通隐私政策》

最后更新：[日期]
版本：v1.0

==================================
重点提示
==================================

我们尊重您的隐私，并致力于保护您的数据安全。在使用本服务前，请仔细阅读本政策。

1. 我们如何收集您的信息
2. 我们如何使用您的信息
3. 我们如何共享、转让、公开披露您的信息
4. 我们如何存储您的信息
5. 您的权利
6. 我们如何保护您的信息
7. 政策的变更
8. 联系我们

==================================
正文
==================================

1. 我们如何收集您的信息

1.1 您主动提供的信息
    - 注册信息：姓名、电话、企业名称、统一社会信用代码
    - 业务信息：合同、订单、库存、价格、客户、出库数据
    - 财务信息：应收账款、付款记录、票据信息
    - 身份信息：法定代表人身份证（实名认证用）

1.2 我们自动收集的信息
    - 设备信息：型号、操作系统、IP 地址、唯一标识符
    - 日志信息：访问时间、点击事件、停留时长
    - 位置信息：基于 GPS 或网络的位置（仅特定功能）

1.3 来自第三方的信息
    - 工商登记信息（接企查查/天眼查/国家企业信用信息系统）
    - 司法公开信息（接法院公开信息）

2. 我们如何使用您的信息

2.1 业务处理
    - 提供您订购的服务
    - 处理订单与支付
    - 客户支持
    
2.2 安全与风控
    - 防欺诈、反洗钱
    - 风险评估与预警
    - 业务合规审查

2.3 业务优化
    - 改善用户体验
    - 个性化推荐
    - 客户调研

2.4 法律合规
    - 履行法律义务
    - 配合监管要求
    - 处理纠纷

2.5 数据指数与风控服务（重要）
    在您额外授权的情况下（详见《数据贡献授权条款》）：
    - 数据脱敏后用于行业指数计算
    - 用于平台风控与预警
    - 提供给金融机构（数据脱敏 + 您的明确授权）

3. 我们如何共享、转让、公开披露您的信息

3.1 共享
    在以下情形下，我们可能与第三方共享您的信息：
    - 取得您的明确授权
    - 法律法规要求
    - 与服务提供商共享（如支付、物流、客服外包，仅限完成服务必需）
    - 关联公司之间（必要范围内）

3.2 转让
    - 公司合并、收购、破产清算等情形下
    - 仅在新主体承诺继续遵守本政策时

3.3 公开披露
    - 法律法规要求
    - 取得您的明确同意

3.4 数据共享接收方清单
    （详见 [附录 A 数据共享方清单]，定期更新公示）

4. 我们如何存储您的信息

4.1 存储位置
    - 中国境内的合规云服务器
    - 不向境外传输（除非您明确同意并完成安全评估）

4.2 存储期限
    - 业务期间：服务使用过程中
    - 注销后：30 日内删除（法律要求保留除外）
    - 法定保留期：财务/税务相关数据保留至法定期限

4.3 存储安全
    - 等保 2 级及以上
    - 加密存储
    - 访问审计

5. 您的权利

5.1 查询、复制权：可查询和导出您的个人信息
5.2 更正、补充权：可更新错误信息
5.3 删除权：满足条件时可申请删除
5.4 撤回授权权：随时撤回数据贡献授权
5.5 注销权：随时注销账号
5.6 投诉权：可向我们或监管部门投诉

行使方式：通过 [APP 设置 / 电话 / 邮件] 联系我们

6. 我们如何保护您的信息

6.1 安全措施
    - 等保 2 级及以上认证
    - 数据加密（传输 TLS 1.3，存储 AES-256）
    - 访问控制（最小权限原则）
    - 安全审计（操作日志可追溯）

6.2 安全事件响应
    - 24 小时内启动应急响应
    - 72 小时内向监管部门报告（如属重大）
    - 及时通知受影响用户

7. 政策变更

### 2.3 文本 3：数据贡献授权条款（核心，必须二次签署）

#### 此为本业务最关键的法律文件

```
《钢链通数据贡献授权专项条款》

【请您逐字阅读，并通过点击"我同意"二次确认。本条款是您是否参与数据贡献服务的关键】

==================================

签订双方：
甲方（数据贡献方）：[企业名称、统一社会信用代码、法定代表人]
乙方（平台运营方）：[公司全称]

==================================

第一条 授权目的
甲方理解：乙方运营钢链通平台，为更好地提供服务并建立行业风险共享机制，需要收集、处理、使用甲方在平台产生的业务数据。本条款是为此目的的专项授权。

第二条 授权范围

2.1 授权数据类型：
    (1) 交易数据：合同、订单、出库、入库
    (2) 应收应付数据：欠款金额、付款记录、账期
    (3) 履约数据：交货时效、质量异议、违约记录
    (4) 库存数据：库存量、规格、周转
    (5) 物流数据：路线、时效、运费
    (6) 价格数据：成交价、报价历史

2.2 授权用途：
    (1) 平台风险预警与征信服务
    (2) 行业指数计算与发布（数据脱敏后）
    (3) 与持牌金融机构联合风控（数据脱敏 + 二次授权）
    (4) 行业研究报告（数据脱敏 + 聚合统计）
    (5) 经甲方明确同意的其他用途

2.3 授权方式：
    (1) 数据脱敏：单家企业数据 100% 脱敏（统计意义而非个体披露）
    (2) 数据分类分级：按敏感度分级处理
    (3) 数据安全：加密存储 + 访问审计

第三条 甲方权利

3.1 撤回权：甲方可随时撤回本授权
    - 撤回方式：通过 APP 设置 / 邮件 privacy@gangliantong.com
    - 撤回后：乙方在 30 日内停止使用甲方数据用于本条款约定用途
    - 撤回不影响：(1) 之前已脱敏入指数库的数据 (2) 法律要求保留的数据

3.2 删除权：甲方可申请删除特定数据（在不违反法律和合理业务需要的前提下）

3.3 知情权：甲方有权要求乙方说明数据使用情况（每年最多 2 次免费查询）

3.4 优先权益：
    作为数据贡献者，甲方享有：
    (1) 免费基础征信查询（每月 50 次）
    (2) 平台风险预警优先推送
    (3) 平台金融服务优先权（保理利率优惠 / 担保费减免）

第四条 乙方义务

4.1 数据安全
    - 等保 2 级及以上保护
    - 加密存储与传输
    - 访问审计与控制

4.2 数据使用限制
    - 不向第三方披露未脱敏数据
    - 不用于本条款约定外的用途
    - 不用于损害甲方利益的活动

4.3 通知义务
    - 政策变更提前 30 日通知
    - 安全事件 24 小时内通知

4.4 删除义务
    - 甲方撤回授权或删除请求后，30 日内执行

第五条 数据共享接收方

5.1 在用于"联合风控"等场景时，乙方将甲方数据脱敏后共享给以下类型的第三方：
    (1) 持牌金融机构（银行/保理/保险公司）
    (2) 持牌征信机构
    (3) 政府监管部门（按法律要求）
    (4) 数据交易所（仅脱敏聚合数据）

5.2 共享前提：
    - 数据脱敏（单家企业不可识别）
    - 接收方与乙方签订数据保护协议
    - 接收方仅在约定范围内使用

5.3 接收方清单将定期在平台公示。

第六条 法律责任

6.1 乙方违反本条款给甲方造成损失的，应承担赔偿责任。

6.2 因甲方提供虚假信息、违规操作给乙方或第三方造成损失的，由甲方承担责任。

6.3 不可抗力造成的损失，按法律规定处理。

第七条 争议解决

7.1 适用中华人民共和国法律
7.2 争议先协商；协商不成提交 [乙方所在地] 人民法院诉讼

第八条 生效与变更

8.1 本条款自甲方点击"我同意"且乙方接收之日起生效。
8.2 重大变更需经甲方同意（继续使用视为同意；不同意可撤回授权）。

第九条 其他

9.1 本条款附属于《钢链通用户服务协议》和《钢链通隐私政策》。
9.2 如本条款与上述文件冲突，以本条款为准。

==================================

【二次确认】

我，[甲方法定代表人姓名]，已仔细阅读上述条款，并同意：

### 2.4 文本 4：数据共享协议（与金融机构）

#### 与银行/保理/保险公司签订的标准模板

```
《数据服务合作协议》

甲方（数据服务提供方）：[钢链通运营公司]
乙方（数据使用方）：[银行/保理公司/保险公司]

第一章 合作内容
1.1 甲方向乙方提供以下数据服务：
    (1) 钢贸真实交易价格指数（CSP）
    (2) 钢贸商信用指数（CSC）
    (3) 钢厂提货完成度指数（CMP）
    (4) [其他根据合同约定]

1.2 数据形式：API 调用 / 月度报告 / 实时推送

第二章 数据保护
2.1 乙方仅在合同约定范围内使用数据，不得：
    (1) 转让、出售、出租给第三方
    (2) 用于与合同约定无关的用途
    (3) 公开披露具体企业数据

2.2 乙方应采取与甲方同等水平的数据安全措施（等保 2 级以上）

2.3 数据保存期：合同期内 + 合同终止后 6 个月内必须删除

第三章 费用与支付
3.1 [按订阅 / 按调用 / 按分润，详细写明]
3.2 月度结算或按合同约定

第四章 责任与风险
4.1 甲方对数据真实性、准确性负责，但不保证基于数据的具体决策结果
4.2 乙方基于数据的决策由乙方独立承担风险
4.3 双方对数据泄露各自承担责任（按谁的安全措施未达标谁负责）

第五章 合规配合
5.1 双方按各自的法律义务确保业务合规
5.2 数据贡献方（钢贸商）撤回授权时，乙方应在 30 日内停止使用相关数据

## 三、合规 SOP（标准操作流程）

### 3.1 数据采集 SOP

```
1. 业务需求评估（PM 提交需求）
   → 评估：是否涉及个人信息？敏感度如何？

2. 法务审查（法务）
   → 评估：是否需要新增授权？是否合规？

3. 用户授权设计（PM + 法务）
   → 设计：协议条款 + 知情同意流程

4. 数据脱敏方案（CTO + 数据团队）
   → 方案：脱敏字段 + 脱敏方法 + K-匿名性验证

5. 安全评估（CTO + 信息安全团队）
   → 评估：等保等级 + 加密 + 访问控制

6. 上线前 review（法务 + CTO + CDO）
   → 确认：所有合规项 OK

7. 上线后审计（每季度）
   → 审计：实际操作是否符合 SOP
```

### 3.2 数据共享 SOP

```
1. 第三方资质审核
   → 营业执照 / 牌照 / 数据保护能力

2. 签订《数据服务合作协议》
   → 法务审核条款

3. 数据脱敏处理
   → 单家企业不可识别

4. 数据传输安全
   → 加密 + API 访问控制 + 审计日志

5. 接收方使用监控
   → 定期检查使用情况

6. 数据贡献者撤回响应
   → 通知接收方在 30 日内停止使用相关数据
```

### 3.3 数据安全事件响应 SOP

```
事件等级分类：
- 一级（严重）：泄露 100 万+ 用户数据 / 重大业务中断
- 二级（重大）：泄露 1 万–100 万用户数据
- 三级（一般）：泄露 1000 以下 / 局部影响
- 四级（轻微）：内部误操作 / 无外部影响

响应时限：
- 一级：1 小时内启动应急 → 24 小时上报监管 → 72 小时通知用户
- 二级：4 小时内 → 48 小时 → 5 日内
- 三级：24 小时内 → 7 日内 → 30 日内
- 四级：72 小时内内部处理

响应步骤：
1. 隔离（停止泄露源）
2. 评估（影响范围）
3. 上报（监管 + 内部）
4. 通知（用户 + 媒体）
5. 修复（漏洞 + 流程）
6. 复盘（事件分析报告）
```

### 3.4 用户权利响应 SOP

```
查询请求：
- 接收方式：在线客服 / 邮件 privacy@gangliantong.com
- 响应时限：15 个工作日内
- 处理流程：核实身份 → 提取数据 → 加密发送

删除请求：
- 接收方式：同上
- 响应时限：15 个工作日内
- 处理流程：核实身份 → 评估法律保留义务 → 软删除（标记）→ 硬删除（30 日后）
- 例外：法律要求保留的数据（如财税）保留至法定期限

撤回授权请求：
- 接收方式：APP 设置 / 邮件
- 响应时限：3 个工作日内
- 处理流程：标记账户为"已撤回" → 30 日内停止数据使用 → 通知第三方接收方

投诉处理：
- 接收方式：客服 / 邮件 / 监管部门转办
