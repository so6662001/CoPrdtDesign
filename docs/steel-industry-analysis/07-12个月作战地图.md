# 12 个月作战地图（按周颗粒度）

> 用途：把"三件套 PLG 飞轮"的落地路径，分解到 52 周的可执行计划。
>
> 适用读者：CEO / 产品总监 / 项目经理 / 各部门负责人。
>
> **核心节奏**：M1–M3 对账单（病毒拉新）→ M4–M6 征信（数据网络）→ M7–M9 资源圈（撮合变现）→ M10–M12 飞轮加速 + 集采 + AI。

| 阶段 | 时间 | 核心任务 | 营收里程碑 |
|---|---|---|---|

## 1. 组织与资源准备（W1–W2）

### 1.1 组建 "PLG 突击小队"（独立于 ERP 团队）

| 角色 | 人数 | 关键能力 |
|---|---|---|
| 产品经理（小队长） | 1 | 既懂 SaaS 又懂钢贸；决策快 |
| 前端 | 1–2 | 微信小程序 + H5 + 移动端优先 |
| 后端 | 2 | 高并发 + 数据 + 风控 |
| 设计 | 0.5 | 兼职/外包，但 UI 必须好看 |
| 增长运营 | 1 | 内容/裂变/数据分析 |
| 内容 / IP（创始人或合伙人亲自做） | 0.5 | 视频号/公众号 |

**总人数 5–7 人**，独立 OKR、独立预算、独立办公室，**避免 ERP 团队稀释**。

### 1.2 立项与目标对齐

- W1 周一：召开"飞轮启动会"，全公司宣布战略转向；
- W1 周三：与董事会确认 12 个月目标（5000w 营收、4w MAU、数据库覆盖 5w 主体）；
- W1 周五：发布 PLG 小队团建+激励方案（按里程碑发奖金）。

### 1.3 增长基建先行

- W1：买好域名（如 ganglian.com 或类似）+ 微信公众号矩阵申请（行情/产品/IP 各一个）+ 视频号 + 抖音；
- W2：搭建增长分析平台（GrowingIO / 神策 / 自建），全埋点准备好；
- W2：选定法务+财务+合规顾问（**这是最容易被忽略的，必须 W2 内确定**）。

### 1.4 法务合规启动（重要）

- W1：约谈 1–2 家专业律所（数据合规方向）；
- W2：起草数据贡献授权专项条款 + 隐私政策 + 服务协议；
- W2：评估"企业征信备案"路径（决定是否申请）。

## 6. 关键风险与应对

| 风险 | 触发信号 | 应对预案 |
|---|---|---|
| **对账单转化率不达预期** | W12 注册转化 < 5% | 切换切入点为"电子合同"或"AI 助手"；不死磕 |
| **数据合规事故** | 任何用户起诉/媒体曝光/监管约谈 | 立即下线相关功能 → 法务危机公关 → 复盘整改 → 重新上线 |
| **黑名单被反诉名誉权** | 收到第一封律师函 | 走 SOP：48h 内回应 + 证据复核 + 必要时移除标签 + 媒体口径统一 |
| **担保交易大额坏账** | 单笔 > 100w 风险事件 | 立即上线"担保金额上限 + 三方仲裁 + 保险兜底" |
| **PLG 团队磨合问题** | M3 末未达 KPI | CEO 直接接管小队 1 个月 + 必要时换人 |
| **现金流告急** | 任何月度现金流为负超 3 个月 | 启动 A 轮融资（建议 W12 后即可启动）；产品向付费倾斜 |
| **关键人员流失** | 小队长/CTO/创始人 IP 任何一人 | 提前签竞业 + 股权激励；建立知识库不依赖单人 |

## 7. 周报 / 月报 / 季报机制

### 7.1 周报（每周五下午发出）

| 模块 | 内容 |
|---|---|
| 本周完成 | 按周计划逐条对照 |

- KPI 全面 review；
- 增长漏斗深度分析；
- 客户访谈 5 家纪要；
- 财务情况；
- 下月调整建议。

### 7.3 季报（每季度末）

- 战略 KPI 大盘；
- 与作战地图偏差分析；
- 战略调整建议；
- 下季度作战地图微调。

## 9. 这份地图的使用建议
