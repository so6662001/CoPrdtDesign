# 3 个月 MVP 启动指南（按周/天颗粒度）

> 本文是从"战略文档"到"实战执行"的桥梁。把 14/15/22 号文档的战略目标分解为 12 周（90 天）可执行的清单。
>
> 适用读者：CEO / 项目经理 / 产品总监 / 各部门负责人。
>
> **核心目标**：
> - **W1–W4**：组建团队 + 上线钢价行情 + 内容矩阵开播
> - **W5–W8**：上线电子对账单 + 扫码出库 MVP + 存量客户激活
> - **W9–W12**：上线 AI 报价初版 + 跑通增长漏斗 + 复盘 + 启动融资
>
> **3 个月末关键 KPI**：
> - DAU ≥ 5,000
> - 公众号粉丝 ≥ 5w
> - 视频号粉丝 ≥ 10w
> - 存量 ERP 客户激活率 ≥ 60%
> - 月发对账单 ≥ 5w 张
> - 完成 Pre-A 融资 LOI

---

## 一、整体节奏

```
W1-W2  组队 + 立项 + 战略拉齐
W3-W4  钢价行情上线 + 内容矩阵开播
W5-W6  电子对账单上线 + 病毒拉新启动
W7-W8  扫码出库 MVP + 存量激活
W9-W10 AI 报价 v1 + 增长漏斗优化
W11-W12 复盘 + 数据合规启动 + 融资 LOI
```

## 十六、最终结论

> **3 个月 MVP 不追求"完美产品"，追求"跑通增长漏斗 + 验证产品价值 + 完成 Pre-A 融资"。**

>
> **最重要的不是某个具体功能，而是：信息钩 + 内容矩阵 + 病毒裂变 + 存量激活——这套增长引擎跑通了。**
