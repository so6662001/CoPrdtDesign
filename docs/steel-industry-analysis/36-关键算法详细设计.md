## 二、算法 1：智能推荐捆号（P3 出库）

### 2.1 业务目标

输入：出库需求（客户/规格/数量/客户偏好）
输出：推荐 N 捆 + 推荐评分 + 推荐理由

### 2.2 输入与约束

```
输入:
  customer_id          客户 ID
  sku_id              规格 ID
  quantity            需求数量（吨）
  client_preferences  客户偏好（钢厂/炉号/...）
  warehouse_id        仓库 ID

候选数据集:
  从 inventory 表查出符合条件的所有可用捆号:
    SELECT bundle_code, weight, heat_no, location_id, in_warehouse_at
    FROM inventory
    WHERE warehouse_id = ?
      AND sku_id = ?
      AND status = 'available'
      AND tenant_id = ?
```

### 2.3 评分模型

每个候选捆号评分 = `客户偏好匹配 × 0.5 + 库龄匹配 × 0.2 + 位置便利 × 0.2 + 捆完整 × 0.1`

#### 子项 A：客户偏好匹配（0-100）

```
preference_score = 0
weight = 0

if client_preferences.mill_codes:
  if bundle.mill_code in client_preferences.mill_codes:
    preference_score += 60
  weight += 60

if client_preferences.heat_no_pattern:

if weight > 0:
  preference_score = preference_score / weight * 100
else:
  preference_score = 100  # 无偏好时, 任何捆都 OK
```

#### 子项 B：库龄匹配（先进先出，0-100）

```
days_in_warehouse = (now - bundle.in_warehouse_at).days

# 30 天以上得分高（早出库），1 天得分低
aging_score = min(100, days_in_warehouse / 90 * 100)
```

#### 子项 C：位置便利（同垛位优先，0-100）

```
# 看候选捆号是否在同一垛位
if 已有推荐捆且本捆与已有同垛位:
  location_score = 100
elif 与最热垛位（本订单已选数最多的垛位）同垛:
  location_score = 80
elif 与已有捆相邻（同区不同垛）:
  location_score = 60

#### 子项 D：捆完整（0-100）

```

elif bundle.weight > 0.7 * standard_bundle_weight:
  complete_score = 60   # 较满

### 2.4 主算法（伪代码）

```
function recommend_bundles(order):
    # Step 1: 获取所有候选捆
    candidates = query_inventory(
        warehouse_id=order.warehouse_id,
        sku_id=order.sku_id,
        status='available'
    )
    
    if not candidates:
        return []  # 无货, 上层处理
    
    # Step 2: 优先客户指定（mill+heat_no）
    if order.client_preferences.mill_codes or order.client_preferences.heat_no_pattern:
        priority = filter_by_preferences(candidates, order.client_preferences)
        if priority:
            candidates = priority  # 用偏好集
    
    # Step 3: 评分
    scored_bundles = []
    selected = []  # 已推荐, 用于位置便利计算
    accumulated_weight = 0
    
    while accumulated_weight < order.quantity and candidates:
        for bundle in candidates:
            bundle.score = compute_score(bundle, order, selected)
        
        # 按 score 倒序
        candidates.sort(key=lambda b: b.score, reverse=True)
        
        # 选 top 1
        chosen = candidates[0]
        selected.append(chosen)
        accumulated_weight += chosen.weight
        candidates.remove(chosen)
    
    # Step 4: 生成推荐理由
    for bundle in selected:
        bundle.reason = generate_reason(bundle, order)
    
    return selected


function generate_reason(bundle, order):
    reasons = []
    if order.client_preferences.mill_codes and bundle.mill_code in order.client_preferences.mill_codes:
        reasons.append(f"客户指定钢厂 {bundle.mill_code}")
    if days_in_warehouse(bundle) > 60:
        reasons.append(f"库龄 {days_in_warehouse(bundle)} 天, 优先出库")
    if is_in_same_location(bundle, selected):
        reasons.append(f"同垛位 {bundle.location_code}")
    if bundle.weight > 0.95 * standard:
        reasons.append("满捆")
    return " + ".join(reasons)
```

### 2.5 异常处理

```
1. 候选数 = 0
   → 返回空列表
   → 上层提示"该规格无库存"
   → 联动业务员通知（其他仓库有？紧急采购？）

2. 候选数 < 需求数
   → 部分推荐 + 标记"待补量"
   → 上层提示"库存不足 X 吨"

3. 客户指定的 mill+heat_no 没货
   → 优先用 preferences 没匹配的候选
   → 上层提示"客户指定炉号无货, 是否接受替代?"

4. 评分异常（如所有候选评分都 < 50）
   → 推荐但提醒人工 review
```

### 2.6 性能要求

- 单次推荐 ≤ 200 ms
- 仓库 100 万捆库存级别可处理（用索引 + 缓存）

## 三、算法 2：AI 4 数字 + 建议价（P4 报价）

### 3.1 业务目标

输入：客户 + 规格 + 数量
输出：4 个数字（成本/最低/客户均价/市场价）+ 建议价区间 + 推荐价

### 3.2 4 个数字的计算

#### 数字 1：加权移动成本

```
function weighted_moving_cost(sku_id, tenant_id):
    # 取该 sku 当前库存的加权成本
    inventory_items = query_inventory(sku_id, tenant_id, status='available')
    
    total_value = 0
    total_quantity = 0
    
    for item in inventory_items:
        # 成本 = 进货成本 + 运费 + 仓储费分摊
        item_cost = item.purchase_price + item.freight_per_unit + item.storage_cost_per_unit
        total_value += item_cost * item.quantity
        total_quantity += item.quantity
    
    if total_quantity == 0:
        return None  # 无库存
    
    return total_value / total_quantity
```

function client_avg_price(customer_id, sku_id, lookback_days=180):
    transactions = query_customer_transactions(

        sku_id=sku_id,

    return total_value / total_weight
```

### 3.3 建议价计算

```
function suggest_price(weighted_cost, recent_low, client_avg, market_price, sku_id):
    
    # 默认合理毛利（按品种）
    reasonable_margin = get_reasonable_margin(sku_id)  # 如 50-80 元/吨
    
    # 下限 = max(成本+合理毛利, 7天最低)
    suggested_min = max(
        weighted_cost + reasonable_margin if weighted_cost else 0,
        recent_low or 0
    )
    
    # 上限 = min(客户历史均价 1.02, 市场价 1.05)
    suggested_max = min(
        client_avg * 1.02 if client_avg else market_price * 1.10,
        market_price * 1.05 if market_price else float('inf')
    )
    
    # 推荐价 = 中位数
    recommended = (suggested_min + suggested_max) / 2
    
    return {
        'suggested_min': suggested_min,
        'suggested_max': suggested_max,
        'recommended': round(recommended / 10) * 10,  # 取整到 10 元
        'reasonable_margin': reasonable_margin
    }
```

```
function check_quote_anomaly(actual_price, suggestion, customer):
    flags = []

    if actual_price < suggestion.weighted_cost:

    # 5. 大单
    if quantity * actual_price > 1_000_000:

        })
    
    # 6. 业务员风险

## 四、算法 3：CSP-V0 真实成交价指数

### 4.1 计算口径

```
对每个 (sku_id, region, date):
    
    # Step 1: 收集该日所有真实出库
    deliveries = query_deliveries(sku_id, region, date)
    
    if not deliveries:
        # 当日无成交, 沿用前一日
        return previous_day_index(sku_id, region, date - 1)
    
    # Step 2: 数据清洗
    # 排除明显异常（与均值偏离超过 30% 的）
    clean_deliveries = remove_outliers(deliveries, threshold=0.3)
    
    # Step 3: 加权平均
    total_value = sum(d.unit_price * d.weight for d in clean_deliveries)
    total_weight = sum(d.weight for d in clean_deliveries)
    
    real_avg_price = total_value / total_weight
    
    # Step 4: 置信度
    confidence = min(1.0, len(clean_deliveries) / 10)
    
    # Step 5: 与基期对比
    base_price = get_base_price(sku_id, region, base_date='2026-01-01')
    index_value = (real_avg_price / base_price) * 100
    
    return {
        'index_value': index_value,
        'real_avg_price': real_avg_price,
        'transaction_volume': total_weight,
        'transaction_count': len(clean_deliveries),
        'confidence': confidence
    }
```

### 4.2 异常检测

```
function remove_outliers(deliveries, threshold=0.3):
    if len(deliveries) < 5:
        return deliveries  # 太少不剔除
    
    prices = [d.unit_price for d in deliveries]
    mean = mean(prices)
    
    return [d for d in deliveries if abs(d.unit_price - mean) / mean < threshold]
```

### 4.3 子指数计算

```
CSP-Master = SUM(子指数 × 权重)

权重按品种成交量动态调整:
  螺纹钢: 35%
  线材: 15%
  热卷: 20%
  中板: 15%
  其他: 15%

权重每月初重新计算（按上月成交量占比）。
```

## 五、算法 4：CSC-V0 客户信用评分

### 5.1 评分维度

| 维度 | 权重 | 说明 |
|---|---|---|
| 付款及时率 | 35% | 按时还款笔数 / 总笔数 |
| 平均逾期天数 | 25% | 历史逾期天数加权 |
| 合作密度 | 15% | 在多少同行处有交易 |
| 司法风险 | 15% | 失信/被执行/裁判文书 |
| 经营稳定性 | 10% | 注册年限 + 注销/吊销 |

### 5.2 各维度评分

#### 付款及时率（0-100）

```
function payment_score(customer):
    transactions = get_customer_payments(customer, last_24_months)
    
    if not transactions:
        return 50  # 新客户中性
    
    on_time = [t for t in transactions if t.overdue_days <= 0]
    ratio = len(on_time) / len(transactions)
    
    return ratio * 100
```

#### 逾期严重度（0-100）

```
function overdue_score(customer):
    transactions = get_customer_payments(customer, last_24_months)
    
    if not transactions:
        return 50
    
    # 逾期天数加权
    total_overdue_weighted = 0
    total_amount = 0
    
    for t in transactions:
        if t.overdue_days > 0:
            # 逾期 30 天权重 1, 60 天权重 2, 90 天权重 4 ...
            weight = (t.overdue_days / 30) ** 2
            total_overdue_weighted += weight * t.amount
        total_amount += t.amount
    
    if total_amount == 0:
        return 50
    
    overdue_severity = total_overdue_weighted / total_amount
    
    # 转换为评分 (反向, 严重度越高分越低)
    score = max(0, 100 - overdue_severity * 50)
    return score
```

#### 合作密度（0-100）

```
function cooperation_score(customer):
    # 在多少家同行处有交易
    cooperated_count = count_distinct_traders(customer)
    
    # 1 家: 50 (单一供应商, 风险中等)
    # 5 家: 80 (合作广, 风险较低)
    # 10+ 家: 100
    
    if cooperated_count <= 1:
        return 50
    elif cooperated_count <= 3:
        return 60
    elif cooperated_count <= 5:
        return 80
    else:
        return min(100, 80 + (cooperated_count - 5) * 4)
```

#### 司法风险（0-100）

```
function legal_score(customer):
    # 接企查查/天眼查
    records = query_court_records(customer.usc_code)
    
    score = 100
    
    if records.被执行次数 > 0:
        score -= records.被执行次数 * 30
    if records.失信被执行人:
        score -= 50
    if records.行政处罚次数 > 0:
        score -= records.行政处罚次数 * 10
    if records.诉讼次数 > 5:
        score -= (records.诉讼次数 - 5) * 5
    
    return max(0, score)
```

#### 经营稳定性（0-100）

```
function stability_score(customer):
    # 接企查查
    business = query_business_registry(customer.usc_code)
    
    # 注册年限
    years = (now - business.founded_at).days / 365
    
    if business.status == '注销':
        return 0
    elif business.status == '吊销':
        return 10
    
    # 年限越长越稳
    if years < 1:
        years_score = 30
    elif years < 3:
        years_score = 50
    elif years < 5:
        years_score = 70
    elif years < 10:
        years_score = 85
    else:
        years_score = 100
    
    return years_score
```

### 5.3 总分

```

## 六、算法 5：CSI-V0 库存周转指数

### 6.1 计算口径

```
对每个 (sku_id, region, date):
    
    # 总库存
    total_inventory = SUM(各企业该 sku 库存)
    
    # 7 日均出库
    deliveries_7d = SUM(过去 7 天该 sku 出库)
    daily_consumption = deliveries_7d / 7
    
    # 周转天数
    if daily_consumption > 0:
        days_of_inventory = total_inventory / daily_consumption
    else:
        days_of_inventory = 999  # 无销售
    
    # 与历史对比
    historical_avg = SUM(过去 12 个月该值) / 12
    relative_level = days_of_inventory / historical_avg
    
    return {
        'total_inventory': total_inventory,
        'daily_consumption': daily_consumption,
        'days_of_inventory': days_of_inventory,
        'historical_avg': historical_avg,
        'relative_level': relative_level,  # > 1 = 库存偏高, < 1 = 偏低
        'level_indicator': map_level(relative_level)
    }


function map_level(ratio):
    if ratio < 0.7: return '极低'
    elif ratio < 0.9: return '偏低'
    elif ratio < 1.1: return '正常'
    elif ratio < 1.3: return '偏高'
    else: return '极高'
```

## 七、算法 6：库存浮盈实时计算

### 7.1 设计

```
对每个 tenant 每个 sku:
    
    floating_pl = quantity_in_stock * (current_market_price - weighted_cost)

实时计算（流式）:
  - 数据源: ClickHouse 实时库存表
  - 触发: 每 5 min 全量计算 / 每次价格变动 incremental
  - 输出: 写入 Redis 供 P5 资金大盘读取

性能:
  - 100 万 sku × tenant 组合
  - 单次计算 < 30s（Spark）
  - Redis 缓存读取 < 10ms
```

### 7.2 伪代码

```
function calculate_floating_pl(tenant_id):
    # Step 1: 获取该 tenant 所有库存
    inventory = redis.get(f'inventory:{tenant_id}:snapshot')

        if not market_price:
            continue
        
        # 浮盈 = (市价 - 成本) × 数量
        pl = (market_price - item.weighted_cost) * item.quantity
        
        total_pl += pl
        breakdown.append({
            'sku_id': item.sku_id,
            'quantity': item.quantity,
            'weighted_cost': item.weighted_cost,
            'market_price': market_price,
            'pl': pl
        })
    
    # 写入 Redis
    redis.set(f'floating_pl:{tenant_id}', {
        'total': total_pl,
        'breakdown': breakdown,
        'updated_at': now()
    }, ttl=300)
    
    return total_pl
```

## 九、算法 8：资金告警引擎

### 9.1 告警类型与规则

```
1. 应收逾期告警
   触发: 客户欠款 > 授信 OR 逾期 > 60 天
   严重度: 金额 × 逾期天数

2. 应付到期告警
   触发: 5 天内有应付到期 AND 现金不足
   严重度: 现金缺口

3. 票据贴现机会
   触发: 30 天内到期票 AND 当前贴现率优于历史均值 0.2%
   严重度: 节省金额

4. 客户新增风险
   触发: CSC-V0 评分下降超过 10 分 OR 新增司法记录
   严重度: 该客户应收金额

5. 集采任务
   触发: 月底 5 天内, 提货差量 > 月度 10%
   严重度: 罚款 + 错失返点

6. 库存压库
   触发: 单 sku 周转天数 > 30 天
   严重度: 库存金额 × 资金成本
```

## 十一、算法 10：库存差异溯源

### 11.1 设计思路

```
function trace_inventory_diff(tenant_id, warehouse_id, sku_id, period_start, period_end):
    
    # Step 1: 上次盘准时间
    last_audit = get_last_inventory_audit(tenant_id, warehouse_id, sku_id)
    
    # Step 2: 期间所有进出库流水
    transactions = query_inventory_transactions(
        warehouse_id=warehouse_id,
        sku_id=sku_id,
        from_time=last_audit.audited_at,
        to_time=period_end
    )
    
    # Step 3: AI 异常检测
    anomalies = []
    
    for t in transactions:
        # A. 操作人异常（非授权）
        if t.operator not in authorized_operators(warehouse_id):
            anomalies.append({
                'type': 'unauthorized_operator',
                'transaction': t,
                'confidence': 0.9
            })
        
        # B. 扫码记录缺失
        if t.type == 'outbound' and not t.scan_records:
            anomalies.append({
                'type': 'missing_scan',
                'transaction': t,
                'confidence': 0.7
            })
        
        # C. 净重偏差异常（已经在出库时校验，这里二次扫描）
        if t.scale_deviation > 0.5:
            anomalies.append({
                'type': 'scale_deviation',
                'transaction': t,
                'confidence': 0.6
            })
        
        # D. 视频快照缺失
        if t.type == 'outbound' and not t.video_snapshot:
            anomalies.append({
                'type': 'missing_video',
                'transaction': t,
                'confidence': 0.5
            })
    
    # Step 4: AI 推断可能原因
    likely_causes = ai_infer_causes(anomalies, diff)
    
    return {
        'transactions': transactions,
        'anomalies': anomalies,
        'likely_causes': likely_causes  # Top 3
    }
```

```
function can_contact_customer(customer_id, requesting_tenant_id, source):
    customer = get_customer(customer_id)
    
    # 1. 主权未设置 → 允许
    if not customer.main_supplier_tenant_id:
        return True, None
    
    # 2. 主权过期 → 允许
    if customer.main_supplier_until < now():
        return True, None
    
    # 3. 当前 tenant 是主权方 → 允许
    if customer.main_supplier_tenant_id == requesting_tenant_id:
        return True, None
    
    # 4. 客户主动解绑过 → 允许
    if customer.client_choice_unbind_at and customer.client_choice_unbind_at > customer.first_dealing_at:
        return True, None
    
    # 5. 否则: 屏蔽
    return False, f'该客户已与其他卖家建立主权关系（剩余 {(customer.main_supplier_until - now()).days} 天）'
