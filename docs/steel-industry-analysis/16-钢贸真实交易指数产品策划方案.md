# 钢贸真实交易数据指数 — 产品策划方案

> 本文是 14 号文档"引擎二：钢贸真实交易数据指数"的完整策划方案，覆盖：产品定位、5 大指数产品、数据采集与脱敏、指数算法、商业化路径、合规设计、技术架构。
>
> 适用读者：CEO / CDO / 产品总监 / 法务 / BD / 投资人。
>
> **本文核心论点**：钢贸真实交易数据指数是平台**最大的护城河**——别人抄不走的、可独立商业化的、可被资本市场按"数据公司"高溢价估值的资产。它的价值远超 SaaS 收入本身，是平台从"工具公司"晋级为"数据基础设施公司"的关键。

---

## 一、战略定位

### 1.1 产品愿景

> **成为中国钢贸行业的"彭博 + 标普"** —— 基于真实交易数据，建立行业权威指数体系，服务银行、保险、对冲基金、期货公司、政府监管、产业链上下游等高价值客户。

### 1.2 为什么是"真实交易数据"

中国现有钢铁行业数据服务商的对比：

| 提供者 | 数据来源 | 局限 |
|---|---|---|
| 上海钢联 / Mysteel | 调查报价 + 期刊采集 | 不是真实成交，是 brokers 报价 |
| 我的钢铁 | 调查报价 | 同上 |
| 央行征信 | 银行借贷数据 | 不覆盖商业信用、付款行为 |
| 期货交易所 | 期货成交 | 只代表期货市场，不代表现货 |
| 各家 ERP（用友/金蝶） | 各自客户数据 | 不集中、不共享、不可商业化 |

**我们的独家性**：
- ✅ **真实成交价**（不是报价）
- ✅ **真实出货量、库存周转、付款行为**（来自 2000+ 钢贸商 ERP 实时数据）
- ✅ **覆盖商业信用**（央行征信不覆盖）
- ✅ **覆盖中小企业**（上市公司财报不覆盖）
- ✅ **细到规格、区域、钢厂**（期货只到品种）

> **这是个体玩家无法做到的、巨头（用友/金蝶）做不出来的、基础设施级别的数据资产。**

### 1.3 为什么这能成为护城河

| 维度 | 说明 |
|---|---|
| **数据网络效应** | 用得人越多，数据越值钱 |
| **冷启动壁垒** | 你需要 2000+ 家钢贸商的真实 ERP 数据，新进入者从 0 做要 5–10 年 |
| **可商业化** | 别人付费可以，自己用也可以（喂养 SaaS 和金融业务） |
| **政策护城河** | 数据合规备案（征信备案 / 数据服务备案）形成牌照壁垒 |
| **资本市场认可** | 数据公司 PS 12–25x（高于 SaaS 的 8–15x） |

## 二、5 大指数产品（M12 上线前 3 个，M24 全套）

### 2.1 指数 1：**钢贸真实成交价指数**（CSP - China Steel-Trading Price Index）

#### 产品定义

基于平台 2000+（未来 20000+）家钢贸商的**真实出库成交数据**，每日计算并发布全国 / 区域 / 品种 / 规格的真实成交价。

#### 关键差异

- vs 上海钢联：钢联是"经纪人电话调查报价"，我们是"真实出库成交"
- vs 期货：期货是金融市场价，我们是现货市场价
- vs 各家 ERP：单家数据有偏，我们是聚合数据

#### 指数体系

```
CSP-Master    全国综合钢贸价格指数（参考基准 2026=100）
   ├─ CSP-Steel-Bar     螺纹钢分指数
   │     ├─ CSP-SB-EC   华东
   │     ├─ CSP-SB-NC   华北
   │     ├─ CSP-SB-SC   华南
   │     └─ ...
   ├─ CSP-Plate         板材分指数
   ├─ CSP-Pipe          管材分指数
   ├─ CSP-Wire          线材分指数
   └─ ...
```

#### 发布频率

- 实时（5 分钟更新一次）
- 日报（早 7 点 / 下午 5 点）
- 周报 / 月报 / 季报 / 年报

#### 客户与定价

| 客户类型 | 用途 | 年费 |
|---|---|---|
| 银行（授信定价、风险监控） | 给钢贸客户授信定价 | 30–100 万/年 |
| 保险公司（信用险定价） | 信用险费率定价 | 20–80 万/年 |
| 对冲基金（量化策略） | 钢铁产业链多空策略 | 50–200 万/年 |
| 期货公司（产业研究） | 现货-期货价差研究 | 30–100 万/年 |
| 钢厂（市场情报） | 出厂定价决策 | 20–80 万/年 |
| 大型钢贸（市场情报） | 自身定价决策 | 5–20 万/年 |
| 政府/行业协会 | 行业景气监测 | 50–300 万/年 |

#### M12 目标

- 5 家金融机构付费（5–10 万/季 试用价）
- 月营收 30 万

### 2.2 指数 2：**钢贸商信用指数**（CSC - China Steel-trader Credit Index）

#### 产品定义

基于平台数据，对每家钢贸商（含买家）生成**信用画像**，包括付款准时率、违约率、合作密度、合作伙伴质量等。

#### 关键数据维度

```
信用画像 (CSC Score)
├─ 付款准时率（30/60/90 天）
├─ 违约次数与严重度
├─ 合作密度（与多少同行有交易）
├─ 合作时长（与各方平均合作年限）
├─ 合作金额（年度/月度规模）
├─ 履约异常（争议次数、退货率）
├─ 法人/股东背景（接企查查）
├─ 司法/失信记录
├─ 经营持续性（注册年限+运营稳定性）
└─ 行业声誉（钢贸圈社区评价）
```

#### 评分输出

- A 优：80–100 分
- B 良：60–79 分
- C 一般：40–59 分
- D 高风险：20–39 分
- E 严重风险：0–19 分（含黑名单）

#### 客户与定价

| 客户 | 用途 | 年费 |
|---|---|---|
| 银行 | 钢贸客户授信前置风控 | 50–200 万/年 |
| 保理公司 | 应收账款风险定价 | 30–100 万/年 |
| 保险公司 | 信用险风控 | 30–100 万/年 |
| 钢厂 | 经销商资格审核 | 10–50 万/年 |
| 大型钢贸 | 客户/供应商授信 | 10–30 万/年 |
| 物流公司 | 客户履约风控 | 5–10 万/年 |

#### 与征信平台的关系

- 征信平台（11 号文档）是 To 钢贸商个人/企业的**查询服务**（99/次 / 999/年）
- CSC 指数是 To 金融机构的**批量数据 API/订阅**
- **数据底层共用**，前端商业化分级

#### M12 目标

- 10 家金融机构付费
- 月营收 80 万

### 2.3 指数 3：**钢厂提货完成度指数**（CMP - China Mill Pickup Index）

#### 产品定义

跟踪各钢厂代理商的月度提货达成率，反映钢厂的产销状况、代理商压货情况、行业景气度。

#### 数据维度

```
钢厂提货完成度
├─ 钢厂层面
│   ├─ 沙钢：本月提货完成率 X%
│   ├─ 中天：本月提货完成率 Y%
│   ├─ 河钢：……
│   └─ ...
├─ 区域层面
│   └─ 各区域代理商整体完成率
└─ 趋势分析
    └─ 12 个月历史趋势 / 季节性
```

#### 客户与定价

| 客户 | 用途 | 年费 |
|---|---|---|
| 钢厂 | 自身经销商管控 | 50–200 万/年 |
| 期货公司 | 现货端基本面研究 | 30–100 万/年 |
| 行业研究机构 | 行业景气度报告 | 20–80 万/年 |
| 政府/工信部 | 产业政策制定 | 50–300 万/年 |

#### M12 目标

- 3 家钢厂 + 2 家研究机构付费
- 月营收 30 万

### 2.4 指数 4：**钢材库存周转指数**（CSI - China Steel Inventory Index）

#### 产品定义

基于平台钢贸商的真实库存数据，发布全国/区域/品种的库存水平 + 周转天数指标。

#### 数据维度

```
库存周转
├─ 总库存量（吨）
├─ 库存周转天数（DTI - Days of Inventory）
├─ 区域库存分布
├─ 品种库存分布
└─ 同比 / 环比 / 趋势
```

#### 客户

- 期货公司、对冲基金（库存是钢价先行指标）
- 钢厂（生产计划参考）
- 大型钢贸（市场判断）
- 媒体（"钢联库存"是市场重要指标，我们提供更细粒度的）

#### 月营收目标 M12: 20 万

---

### 2.5 指数 5：**钢贸资金压力指数**（CFP - China Steel-trading Financial Pressure）

#### 产品定义

反映钢贸行业整体应收账款规模、票据资金占用、融资需求等，给央行/监管部门/行业协会提供宏观参考。

#### 数据维度

```
资金压力
├─ 行业平均应收账款 / 营收比
├─ 行业平均票据占资金比
├─ 行业逾期率
├─ 行业融资需求指数
└─ 区域差异
```

#### 客户

- 央行 / 银保监会
- 工信部 / 行业协会
- 大型银行总行（产业研究部）
- 智库 / 大学

#### 特点

- 客户少但单价极高（50–500 万/年）
- 政策导向，与监管形成良性互动
- 是 IPO 路上的重要"政策友好品牌资产"

#### 月营收目标 M12: 暂未上线（M18+ 推出）

## 三、数据采集与脱敏

### 3.1 数据来源

| 来源 | 类型 | 采集频率 |
|---|---|---|
| 平台 ERP 客户（出库/入库） | 真实交易 | 实时 |
| 平台对账单 SaaS（应收/收款） | 应收应付 | 实时 |
| 平台 AI 报价（成交价） | 报价/成交 | 实时 |
| 平台扫码出库（物流/履约） | 履约 | 实时 |
| 平台资金大盘（票据/融资） | 资金 | 实时 |
| 接企查查 / 天眼查（工商） | 主体 | 日更 |
| 接钢联 / Mysteel（外部参考） | 报价 | 日更 |

### 3.2 数据合规：3 道防线

#### 防线 1：用户授权

- 用户协议明示"数据使用范围"
- 提供"撤回授权 + 数据删除"通道
- 单独的"数据贡献"专项条款（必须二次签署）

#### 防线 2：数据脱敏

```
原始数据 → 脱敏处理 → 入指数库

脱敏规则：
- 单家企业数据不可识别（统计意义而非个体披露）
- 单笔交易细节抽取后金额/对手方脱敏
- 时间窗口模糊化（精确到日级而非秒级）
- 地理颗粒度模糊化（区域级而非具体仓库）
- K-匿名性 + 差分隐私技术
```

#### 防线 3：合规备案

| 备案 | 说明 | 时间 |
|---|---|---|
| 企业征信备案 | 央行下属机构 | 6–12 个月 |
| 数据服务备案 | 网信办/工信部 | 3–6 个月 |
| 等保 2 级 | 公安部三所 | 3 个月 |
| 数据出境评估 | 网信办（如海外客户） | 视情况 |

### 3.3 数据用途分级

| 级别 | 用途 | 数据形式 |
|---|---|---|
| L1 | 自用（喂养自家 SaaS / 风控） | 完整 |
| L2 | 贡献者免费查询（钢贸商查同行） | 部分脱敏 |
| L3 | 付费查询（金融机构） | 完整脱敏 |
| L4 | 公开发布（指数/月报） | 高度聚合 |

## 四、指数算法设计

### 4.1 价格指数算法（CSP）

```
CSP-Master(t) = ∑ (W_i × P_i(t) / P_i(t_0))
其中：
  W_i = 各品种成交量权重（动态调整）
  P_i(t) = 该品种全平台真实成交价加权均价
  t_0 = 基期（2026年1月1日 = 100）

子指数：
  CSP-SB-EC(t) = 螺纹钢华东子指数（同样算法）
```

### 4.2 信用指数算法（CSC）

```
CSC_Score(企业 X) = w1 × Payment_Score
                  + w2 × Default_Score
                  + w3 × Cooperation_Density
                  + w4 × Legal_Score
                  + w5 × Industry_Reputation

权重示例：
  w1 = 0.35  付款行为
  w2 = 0.25  违约严重度
  w3 = 0.15  合作密度
  w4 = 0.15  司法
  w5 = 0.10  声誉

每个 Score 子项基于具体规则计算，可解释。
```

### 4.3 算法可解释性（关键）

每个指数 / 评分必须提供：
- 计算口径文档（公开）
- 各分项权重（公开）
- 历史数据回测（公开）
- 第三方机构（如四大）背书（必要时）

> **可解释性是数据指数被金融机构采用的前提**。黑箱算法没人买。

## 六、合规与法务（最关键的成功因素）

### 6.1 关键合规风险

| 风险 | 应对 |
|---|---|
| **数据贡献者声明数据归属** | 协议明确：贡献者保留数据所有权，平台获脱敏使用权 |
| **被监管认定为"非法征信"** | 不冒用"征信"二字（除非备案）；定位"数据服务" |
| **数据被滥用** | 脱敏 SOP + 用户撤回 + 用途审计 |
| **被起诉名誉权** | 评分可申诉 + 申诉 SOP + 法务保险 |
| **海外客户数据出境** | 网信办出境安全评估 |
| **算法歧视/偏见** | 算法可解释性 + 第三方审计 |

### 6.2 法务团队配置

- 数据合规律师 1 人（专职）
- 金融合规律师 1 人（兼职）
- 外部律所合作 1–2 家（数据 + 金融领域专家）

### 6.3 法务里程碑

| 时间 | 里程碑 |
|---|---|
| M2 | 用户协议 / 隐私政策 / 数据贡献条款定稿 |
| M4 | 等保 2 级过审 |
| M6 | 启动企业征信备案 / 数据服务备案 |
| M12 | 备案下来 / 第三方算法审计完成 |

## 八、与其他业务的联动

### 8.1 数据指数 → SaaS 标品

- 钢价行情 + AI 解读 → 用 CSP 数据

### 8.3 数据指数 → 金融分润

- CSC 信用指数 → 银行/保理风控决策

### 8.4 数据指数 → IPO 估值

- 数据公司 PS 12–25x（高于 SaaS 8–15x）
- 给整体估值带来溢价

## 十一、最终战略意义

### 11.1 数据指数对公司的 4 大价值

1. **第二增长曲线**：M24 后每年贡献 5000 万 → 2 亿 → 5 亿+ 的高毛利收入
