# PRD — 五个 SaaS 标品产品矩阵

> 本文是 14 号文档"引擎一：产业 SaaS 标品矩阵"的完整 PRD 集合，覆盖 5 个 SaaS 标品（钢价行情 / 电子对账单 / 扫码出库 / AI 报价 / 资金大盘+电子合同）以及它们之间的联动设计。
>
> 适用读者：产品经理、研发、UI/UX、测试、销售、客户成功。
>
> **本文档约定**：每个 SaaS 都按"业务目标 / 用户角色 / 核心流程 / 数据模型 / 功能清单 / 商业模式 / 与其他 SaaS 联动"6 段式呈现。

---

## 0. 整体设计原则

### 0.1 标品哲学

| 原则 | 说明 |
|---|---|
| **标准化** | 所有客户用同一个产品（必要时配置化，不做定制开发） |
| **模块化** | 5 个产品独立可买、可组合（套餐折扣 + 单买价） |
| **移动优先** | 90% 功能在小程序/APP 完成，PC 是辅助 |
| **互联互通** | 5 个 SaaS 共用一套用户/数据/权限/计费 |
| **数据沉淀** | 所有用户行为/交易/履约数据都进入数据中台（详见 16 号文档） |
| **病毒拉新** | 每个产品都有"病毒位"——发给客户/同行/司机时附带平台引导 |

### 0.2 5 个 SaaS 联动总图

```
   ┌──────────────────────────────────────────────────┐
   │  钢价行情 + AI 解读                              │
   │  (信息钩, 每日打开)                              │
   └──────────────────────────────────────────────────┘
                      ↓ 内容引导
   ┌──────────────────────────────────────────────────┐
   │  AI 报价助手                                     │
   │  (业务员每天 50+ 次)                             │
   └──────────────────────────────────────────────────┘
            ↓ 报价转化为订单         ↓ 报价数据
   ┌──────────────┐         ┌──────────────────────┐
   │  扫码出库    │ ←─同步─→│  电子对账单           │
   │  (仓管每天)  │         │  (财务每月)           │
   └──────────────┘         └──────────────────────┘
            ↓ 出库进资金账    ↓ 应收数据
   ┌──────────────────────────────────────────────────┐
   │  资金大盘 + 电子合同                             │
   │  (老板每天 5+ 次)                                │
   └──────────────────────────────────────────────────┘
                      ↓ 全数据沉淀
   ┌──────────────────────────────────────────────────┐
   │  数据指数 / 集采 / 金融分润 (引擎二/三)           │
   └──────────────────────────────────────────────────┘
```

### 0.3 商业模式与定价

| 套餐 | 内容 | 年费 | 目标客户 |
|---|---|---|---|
| **基础版（免费）** | 钢价行情（基础）+ 电子对账单（限 10 张/月）+ 钢贸圈社区 | 0 | 拉新、个人采购员、中小钢贸商 |
| **业务版** | + AI 报价（限 100 次/月）+ 扫码出库（限 500 单/月） | 4,980 元/年 | 小型钢贸商（5–15 人） |
| **企业版** | + 全部 5 个 SaaS 不限量 + 资金大盘 + 电子合同 + 钢价深度 | 19,800 元/年 | 中型钢贸商（30–100 人） |
| **集团版** | + 多公司多账套 + API + 自定义 + 数据指数 + 优先客服 | 88,000 元/年 + 实施费 | 大型钢贸（>100 人） |

加值服务：
- 数据指数 / 集采 / 金融分润 按使用计费（详见 11 / 14 / 16 号文档）

## 1. SaaS 1：钢价行情 + AI 解读

### 1.1 业务目标

| 目标 | 指标 |
|---|---|
| 日活引擎 | M12 末 DAU ≥ 30,000 |
| 拉新 | 公众号粉 ≥ 50w / 视频号粉 ≥ 100w |
| 付费转化 | 深度内容订阅 999/年 ≥ 20,000 单 |
| 数据沉淀 | 用户关注品种 / 阅读偏好回流到数据中台 |

### 1.2 用户角色

| 角色 | 权益 |
|---|---|
| 免费用户 | 早 7 点行情推送 / 基础解读 / 行情历史曲线（30 天） |
| 付费用户（999/年） | + AI 深度解读 / 行情历史曲线（5 年）/ 自定义行情订阅 / 内部周报 |
| 企业用户 | + 行情 API / 团队多账号 / 数据导出 |

### 1.3 核心流程

#### 1.3.1 早间行情推送

```
[每天 06:00]
    └─ 数据采集（接钢联/Mysteel + 自有平台真实成交）
        └─ AI 模型生成解读（结构化）
            └─ 编辑审核（10 分钟内）
                └─ 06:50 多渠道推送
                    ├─ 公众号
                    ├─ 视频号（短视频版）
                    ├─ APP/小程序内推
                    ├─ 企业微信机器人
                    └─ 短信/邮件（订阅用户）
```

#### 1.3.2 AI 解读结构

```
今日早报（2026-04-27）

【一句话总结】
螺纹小幅上涨，板材偏强，市场情绪转好

【关键价格】
- 螺纹钢上海现货均价：4,150 (+20)
- 螺纹钢期货 RB2510：3,920 (+15)
- 热卷上海现货：4,280 (+30)
- 板材华东：4,120 (+10)

【影响因素】
- ✓ 利好：唐山限产消息发酵 / 工地节后复工集中
- ✗ 利空：库存仍处于 12 个月高位
- ⚠️ 关注：央行 LPR 周三公布

【AI 建议】
螺纹短期偏强但库存压力大，建议高位逢高出货；
长材采购方可考虑分批补货。

【独家数据】
（基于平台 2000+ 钢贸商真实数据）
- 华东出货量较昨日 +12%
- 江苏地区库存仍处于 12 个月高位
- 钢贸商持仓信心指数：62（偏乐观）
```

```
UserBehaviorLog

ProprietaryDataPoint
  - data_date, sku_id, region

  - real_avg_price

```

## 3. SaaS 3：扫码出库 SaaS

### 3.1 业务目标

| 目标 | 指标 |
|---|---|
| 高频高黏 | 仓管每天用 30+ 次，强依赖 |
| 数据沉淀 | 出库 / 物流 / 履约数据进入数据中台 |
| 业务变现 | 通过出库自动触发金融服务（保理/担保） |

### 3.2 用户角色

| 角色 | 权益 |
|---|---|
| 仓管 | 扫码出库 + 装车监控 + 司机签收 |
| 财务 | 出库自动同步财务（应收+1） |
| 老板 | 出库实时可见 + 异常预警 |
| 司机 | 司机 APP（导航 + 扫码 + 签收 + 拍照） |
| 客户 | 收货端 H5（验货 + 电子签字） |

### 3.3 核心流程

#### 3.3.1 出库主流程

```
[销售合同生成 → 出库单]
    └─ 仓管在 PAD/手机扫描提货单
        └─ 系统自动按"客户指定钢厂+炉号优先级+先进先出"推荐到具体捆号
            └─ 仓管扫码确认装车（每捆扫一次）
                └─ 系统自动生成炉号清单 + 质保书 PDF
                    └─ 磅秤直连读取毛重/皮重/净重
                        └─ 系统强校验：理计 vs 过磅偏差 ±0.3%
                            └─ 异常报警 / 正常通过
                                └─ 司机手机扫码确认 + 拍照 + GPS
                                    └─ 自动生成出库回执
                                        └─ 同步财务（应收+1）+ 客户对账单 + 数据中台
                                            └─ 司机送货途中 GPS 共享给客户
                                                └─ 客户验货 → H5 电子签字
                                                    └─ 闭环
```

## 4. SaaS 4：AI 报价助手

### 4.1 业务目标

| 目标 | 指标 |
|---|---|
| 业务员高频用 | M12 月报价单数 ≥ 100w 张 / 业务员日均 30+ 次 |
| 老板风控 | 业务员私单飞单识别率 ≥ 90% |
| 数据沉淀 | 报价 / 成交 / 客户行为数据回流支撑数据指数 |

### 4.2 用户角色

| 角色 | 权益 |
|---|---|
| 业务员 | 一键报价 / 历史报价查询 / 客户画像 |
| 老板 | 报价审批 / 异常预警 / 业务员行为分析 |
| 客户 | 收到正规报价单 H5 / 在线确认/还价/拒绝 |

### 4.3 核心流程

#### 4.3.1 业务员报价主流程

```
[业务员手机打开 AI 报价]
    └─ 输入客户名 + 规格 + 数量（语音可输入）
        └─ AI 0.5 秒返回 4 个数字 + 1 个建议
            ├─ 加权移动成本：4090
            ├─ 最近 7 天最低成交价：4120
            ├─ 该客户历史均价：4180
            ├─ 当前市场基准价：4150（接钢联）
            └─ AI 建议报价区间：4150–4180（毛利 60–90/吨）
        └─ 业务员选择：报价 4170
            └─ 系统自动生成报价单 H5
                └─ 一键发微信给客户
                    └─ 客户扫码看 H5（含报价 + 锁价时长 + 一键确认）
                        └─ 客户点"确认下单"
                            └─ 自动生成合同 + 触发出库 + 入账
```

#### 4.3.2 老板审批流（异常报价才触发）

```
业务员报价 < 成本价 5% / 低于客户历史均价 10% / 高于市场价 5%
    → 自动触发"老板审批"
        → 老板手机收到推送（含 4 数字 + 建议 + 业务员说明）
            → 老板点"准/驳/改"
                → 业务员收到通知
```
