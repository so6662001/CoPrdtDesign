# 六家钢铁产业互联网竞品深度分析

> 本文是对中国钢铁产业互联网领域 6 家代表性公司的全维度对照研究：钢银电商、找钢网、欧冶云商、中钢网、欧冶链金、物产链。
>
> 维度：业务模式 / 财务表现 / 估值 / IPO 路径 / 失败教训 / 我们的差异化机会。
>
> 适用读者：CEO / 产品总监 / 投资人 / BD。
>
> **特别说明**：本文基于公开资料、行业报道与逻辑推断，部分财务/估值数据可能与实际有出入，**仅供战略参考，不作投资依据**。

## 二、逐家深度分析

### 2.1 钢银电商（钢银）

#### 业务模式

- **核心业务**：寄售（钢厂寄货平台代销）+ 任你花（采购融资）+ 票据贴现
- **流量来源**：母公司上海钢联（资讯+价格数据）导流
- **服务对象**：买家（采购方+小钢贸商）

#### 财务表现（公开资料推断）

| 指标 | 典型情况 |
|---|---|
| 年 GMV | 1500–2000 亿（峰值） |
| 营业收入 | 1000+ 亿（自营+寄售走账） |
| 毛利率 | < 0.5% |
| 净利率 | 0.1–0.3% |
| 年净利润 | 1–3 亿 |
| 应收账款占比 | 较高 |

#### IPO 路径

- 2014 年新三板挂牌（835092）
- 多次冲击主板 IPO（包括 2018、2020、2022），均失败
- 主因：监管认定收入"非互联网公司"、关联交易复杂、金融业务合规风险

#### 估值

- 新三板长期估值 30–50 亿（市值低迷）
- 主板预期估值 100 亿+（未实现）

#### 关键失败教训

| 教训 | 描述 |
|---|---|
| 1. 母公司既得利益冲突 | 钢联是行业资讯中立者，做电商被钢贸圈抵制 |
| 2. 撮合用户低活留存 | 月活留存 < 10%，被迫转自营 |
| 3. 自营走账被监管质疑 | 收入是"贸易流水"还是"平台佣金"分不清 |
| 4. 任你花金融监管风险 | 多次被问询是否影子银行 |
| 5. 估值故事不互联网 | 资本市场认定为贸易+金融公司 |

#### 对我们的启示

- 数据资产价值（钢联资讯成为护城河）—— 学
- 自营+金融的死路 —— 避
- 关联交易复杂性 —— 避

---

### 2.2 找钢网

#### 业务模式

- **2012–2014**：纯撮合（钢铁版淘宝）—— **失败**
- **2014–2016**：自营+寄售
- **2016–2024**：S2B 赋能 + 胖猫物流 + 加工配送中心 + 胖猫金服 + 找钢指数

#### 财务表现（公开资料推断）

| 指标 | 典型情况 |
|---|---|
| 年 GMV | 500–1000 亿 |
| 营业收入 | 100–300 亿（自营+服务） |
| 毛利率 | 1–3% |
| 净利率 | 长期亏损或微利 |

#### IPO 路径

- 2017 年首次冲击 A 股 IPO，失败
- 2018 年转港交所 IPO，失败
- 2022 年与 SPAC（Aquila Acquisition Corporation）合并上市
- 2024 年合并失败 / 估值大幅缩水

#### 估值

- 一级市场最高估值 200+ 亿（2018–2019 年）
- SPAC 合并目标估值 30 亿美元
- 实际估值大幅缩水（公开报道指 SPAC 合并最终告吹）

#### 关键失败教训

| 教训 | 描述 |
|---|---|
| 1. 撮合做不动 | 行业内卷，毛利击穿 |
| 2. 转自营毛利低 | 自营贸易毛利率 < 1% |
| 3. 多元化稀释估值故事 | 撮合+自营+物流+加工+金融 — 资本市场看不懂 |
| 4. 物流重资产负担 | 胖猫物流成本沉淀 |
| 5. 金融业务监管风险 | 与钢银同病 |
| 6. IPO 估值故事不清晰 | 互联网?贸易?金融?物流?SaaS? |

#### 找钢网真正"做下去"的部分

- **物流（胖猫物流）**：钢材专业物流是真实痛点
- **加工配送中心**：30+ 中心，给下游加工厂提供服务
- **S2B 赋能**：让 5000+ 中小钢贸商使用平台

#### 对我们的启示

- 产业链延伸的"补位思路" —— 学
- S2B 赋能模式 —— 学
- 物流业务必要性 —— 学（但要轻资产）
- 多元化稀释估值 —— 避
- 重资产物流陷阱 —— 避

### 2.3 欧冶云商

#### 业务模式

- **核心业务**：自营 + 撮合 + 物流（自有 + 撮合）+ 加工配送 + 金融（仓单 + 保理）+ 数据
- **背景**：中国宝武集团旗下，国资+国企背景，有钢厂资源
- **服务对象**：宝武体系 + 上下游钢厂、贸易商、加工厂

#### 财务表现（公开资料推断）

| 指标 | 典型情况 |
|---|---|
| 年 GMV | 1000+ 亿（国资体系内） |
| 营业收入 | 500+ 亿（含自营） |
| 毛利率 | 2–3%（依托宝武资源） |
| 净利率 | 微利或盈亏平衡 |

#### IPO 路径

- 多次传出 IPO 计划，但因股东结构复杂、关联交易、行业监管收紧等原因未实质推进
- 当前重心：服务宝武集团内部 + 政府数字化项目

#### 估值

- 一级市场估值 200–300 亿（基于股东背景）
- 资本市场实际溢价待定

#### 关键失败教训

| 教训 | 描述 |
|---|---|
| 1. 国资股东结构复杂 | 决策慢、市场化弱、IPO 难 |
| 2. 与宝武关联交易过多 | 独立性受质疑 |
| 3. 自营+金融模式与钢银/找钢网相似 | 同病 |
| 4. 体制内创新难 | 难有真正颠覆性创新 |

#### 对我们的启示

- 国资背景是**双刃剑**——资源好但创新难
- 关联交易合规性必须早期设计
- 体制外创业有更大灵活性

---

### 2.4 中钢网

#### 业务模式

- **2010–2015**：信息撮合（早期"钢铁信息黄页"）
- **2015–2020**：转向自营 + 商超
- **2020+**：业务边缘化

#### 财务表现

- 业务规模逐年萎缩
- 多次 IPO 失败后基本停滞

#### 关键失败教训

| 教训 | 描述 |
|---|---|
| 1. 起步早但跟不上时代 | 移动互联网/数据化转型慢 |
| 2. 信息撮合到自营的尴尬过渡 | 没找到差异化点 |
| 3. 资本运作能力弱 | 多次 IPO 失败后无力转型 |

#### 对我们的启示

- 创新节奏跟不上 = 死路
- 数据化、移动化、AI 化必须持续投入

---

### 2.5 欧冶链金

#### 业务模式

- **核心业务**：钢厂端的供应链金融服务（票据 / 仓单 / 保理）
- **背景**：中国宝武分拆出来的金融科技公司
- **服务对象**：宝武集团内的钢厂、贸易商

#### 关键特点

- 业务体量较小但相对**专注**
- 主打"产业链金融科技"
- 持有相关金融牌照（保理、票据）

#### 对我们的启示

- 专注有专注的好处
- 持牌方主体 = 合规优势
- 但**单纯做金融** = 业务上限受限于体系内

---

### 2.6 物产链（物产中大供应链）

#### 业务模式

- **核心业务**：大宗商品供应链（含钢材、有色、能源、化工）
- **背景**：物产中大（600704）A 股上市公司
- **服务对象**：上下游产业链客户

#### 财务表现

- 物产中大 2024 年营收 5000+ 亿（含多业务）
- 毛利率 2–3%（贸易公司水平）
- 净利率 0.5–1%

#### 估值

- 物产中大 A 股市值 200+ 亿
- 按 PE 估值（贸易公司）

#### 对我们的启示

- 大宗商品贸易企业 + 数字化 = 仍然是贸易公司估值
- 不是"披上数字化外衣"就能升级估值

## 三、6 家共同的失败模式

### 3.1 共同模式 1：撮合走不通

| 公司 | 撮合尝试 | 结果 |
|---|---|---|
| 钢银 | 部分尝试 | 撤退到寄售 |
| 找钢网 | 全力尝试 | 撤退到自营 |
| 欧冶云商 | 部分尝试 | 撤退到自营+物流 |
| 中钢网 | 信息撮合 | 业务萎缩 |

> **共识**：钢铁行业的"撮合"商业模式不可持续。

### 3.2 共同模式 2：自营是"温水煮青蛙"

- 撮合做不下去 → 转自营 → GMV 上升但毛利低 → 估值天花板锁死

| 公司 | 自营占比 | 估值结果 |
|---|---|---|
| 钢银 | 90%+ | 新三板 30–50 亿 |
| 找钢网 | 70%+ | SPAC 失败 |
| 欧冶云商 | 70%+ | IPO 待定 |

### 3.3 共同模式 3：金融业务是双刃剑

- 收入大但监管严 / 不良风险高 / 上市受阻

### 3.4 共同模式 4：业务多元化稀释估值

- 撮合 + 自营 + 物流 + 加工 + 金融 + 数据
- 资本市场看不懂"你到底是什么公司"

### 3.5 共同模式 5：估值故事不互联网

- 5 家中没有一家成功讲出"互联网公司"故事
- 都被资本市场最终按"贸易+金融"估值

## 五、6 家的"做对的部分" — 我们应该学

### 5.1 学钢银的：**资讯+服务漏斗**

- 钢联的"行情资讯免费 → 服务付费"是经过验证的漏斗
- 我们的钢价行情 SaaS 应该走这个路径

### 5.2 学找钢网的：**产业链补位思路 + S2B 赋能**

- 看哪里有真痛点就去做（物流/加工/金融）
- 把自家能力包装成 SaaS 卖给中小同行

### 5.3 学欧冶云商的：**国资合作的稳定性**

- 与钢厂深度战略合作（虽然我们体外，但可以战略合作）
- 与政府 / 行业协会建立联系

### 5.4 学欧冶链金的：**金融业务的"专注 + 持牌"**

- 不贪多，专注做好金融分润
- 100% 持牌方主体，不冒险

### 5.5 学找钢指数的：**数据指数的雏形**

- 找钢网做"找钢指数"是对的方向，但我们要做得更深更专业

## 七、6 家共同教训提炼为 5 大铁律（必读）

> 这 5 条是基于 6 家失败教训提炼出来的"中国钢铁产业互联网铁律"，违反任何一条都可能万劫不复。

### 铁律 1：**永远不做"以 GMV 为核心 KPI"**

- 钢银/找钢网/欧冶都被 GMV 故事拖累
- KPI 应聚焦：付费客户数、NDR、净利率、估值故事的 PS 倍数

### 铁律 2：**永远不做"被迫转自营"**

- 撮合 → 自营 → 估值锁死，6 家中 4 家踩过
- 第一天就避开这条路

### 铁律 3：**永远不做"重资产金融"**

- 钢银/找钢网/欧冶都受困于此
- 100% 持牌方主体 + 平台分润，是唯一健康路径

### 铁律 4：**永远不做"业务大而全"**

- 找钢网/欧冶都是反面教材
- **聚焦：SaaS + 数据指数 + 轻资产生态运营**——三件事做好就够了

### 铁律 5：**永远要讲"互联网公司"故事**

- 收入结构 / 财务报表 / 关联交易 / 估值倍数都按互联网公司设计
- 不要让自己的报表"看起来像贸易公司"

## 八、我们的差异化机会矩阵

| 维度 | 6 家共同短板 | 我们的差异化 |
|---|---|---|
| **SaaS 标品** | 都没真正做好 | **核心产品矩阵** |
| **真实交易数据指数** | 钢联是调查报价 / 期货是金融市场 | **2000 家真实成交独家** |
| **轻资产生态** | 都是重资产 | **平台不持仓不持牌不放贷** |
| **内容+社区** | 都不强 | **创始人 IP + 行业大 V + AI 内容** |
| **AI Agent** | 都没充分用 | **报价/调货/对账 AI 全场景** |
| **集采议价** | 找钢网/欧冶都尝试但不彻底 | **2000 家联合议价的规模** |
| **客户主权机制** | 都没设计 | **6 个月主权 + 撬客封禁** |
| **客户日活引擎** | 都是低频工具 | **3 类钩子 + 5 个替代场景** |

## 九、最终的"反向定位"

### 9.1 我们要成为的

> **"懂钢贸的中国版 Salesforce + 行业版彭博"**
>
> = 产业 SaaS 标品矩阵 + 真实交易数据指数 + 轻资产生态运营

### 9.2 我们绝不成为的

| 不成为 | 原因 |
|---|---|
| 钢银 2.0 | 母公司冲突 + 自营+金融重资产 |
| 找钢网 2.0 | 多元化 + 重资产 + 估值故事不清 |
| 欧冶云商 2.0 | 国资体制束缚 |
| 中钢网 2.0 | 数据化跟不上 |

### 9.3 资本市场最终呈现

| 当 6 家被估值为 | 我们应该被估值为 |
|---|---|
| 贸易公司（PE 5–10x） | 互联网公司（PS 8–15x） |
| 金融公司（PB 1–2x） | 数据公司（PS 12–25x） |
| 物流公司（PE 10–15x） | 平台公司（PS 10–20x） |

**估值差异 5–10 倍。这就是"差异化战略"的最终价值。**

## 十一、最终结论

> **中国钢铁产业互联网领域过去 14 年（2010–2024）共有 6 家代表性公司，没有一家真正"赢"。**
>
> **它们的共同失败 = 我们的差异化机会。**
>
