# 资源圈业务重新设计 — 从"对立面"到"加速器"

> 本文是对 04 / 05 / 07 三份文档中"资源圈/找货撮合"业务的**重大设计纠偏**。
>
> **触发原因**：原设计本质上是"找钢网模式"——公开资源池 + 多方竞价撮合，这种模式会激化钢贸商之间的内卷竞争，是行业从业者**最反感**的产品形态。找钢网过去走过这条路，付出过沉重代价。
>
> **新设计核心**：从"撮合公开市场"转向"赋能私域生意"，让平台**成为钢贸商的加速器和后盾，而不是把他们绑到一个互相杀价的擂台上**。

---

## 一、为什么"公开撮合"在钢贸圈是死路（深度复盘）

### 1.1 找钢网的真实历史教训

找钢网早期（2012–2015）做的就是"公开资源池 + 多家比价撮合"。结果发生了什么：

1. **价格透明化 → 毛利击穿**：
   - 同一规格在平台上挂出，立即引发"5 家压 4 家"的连环压价；
   - 钢贸商把毛利从 30–50 元/吨打到 5–10 元/吨；
   - 行业平均毛利率被压到 1% 以下。
2. **大宗交易者愤而撤离**：
   - 真正手握库存的大贸易商发现"挂上去就是给同行拆台"，集体抵制；
   - 平台留下的全是"既无库存也无客户"的纯撮合贩子；
   - 资源池质量急剧下降。
3. **找钢网被迫转型**：
   - 后期转向 **自营 + 寄售 + 物流 + 金融**，去掉公开撮合属性；
   - 最终走向"钢厂直供物流配送商"角色，跟早期"找货平台"愿景完全不同；
   - **付出了 5 年时间和数十亿教训才完成转型**。

### 1.2 钢贸圈的"反竞争"文化（行业潜规则）

钢贸是个**重关系、重信用、重私域**的传统行业，有几条公认的"江湖规矩"：

| 潜规则 | 含义 | 触犯后果 |
|---|---|---|
| **不抢同行客户** | 知道这个客户是谁的，不主动报价撬墙 | 被同行联合抵制 |
| **不公开报价** | 价格只对客户报，不在群里晒 | 被视为"扰乱市场" |
| **同行有难互相帮** | 调货、垫资、转贷互相照应 | 不帮的会被孤立 |
| **价格底线靠默契** | 区域内同行心照不宣维持一个底价 | 砸盘者被全行业拉黑 |
| **关系链 = 资产** | 老客户、老钢厂、老司机都是私产 | 撬动 = 断人财路 |

> **平台一旦让公开比价发生，就等于在挑战行业的全部潜规则。**
> 你的 2000 个 ERP 客户里，**至少 1500 家会立刻把你拉黑**。

### 1.3 原设计的根本性错误

原 PRD 的资源圈业务，本质上是把每个钢贸商的库存挂到公海，让其他钢贸商围观+比价。这违反了三件事：

- **违反了私域逻辑**：钢贸生意核心资产是"我的客户 + 我的钢厂关系"，公开化等于把私产充公；
- **违反了同行伦理**：公开比价就是公开砸盘，行业立刻反弹；
- **违反了商业模式自洽性**：你的 ERP 客户用得越多，越受伤，怎么可能形成飞轮？

**结论**：必须推翻重做。

## 二、重新定义资源圈业务的"灵魂"

### 2.1 一句话原则

> **平台不做"撮合公开市场的裁判员"，平台做"放大每个钢贸商私域生意的加速器"。**

### 2.2 三条不可违反的设计铁律

| # | 铁律 | 反面（绝不能做） |
|---|---|---|
| 1 | **私域优先**：默认所有库存/客户/价格都是用户私产，平台不可见也不发布 | ❌ 默认公开资源池 |
| 2 | **不让同行变对手**：拒绝任何"同行之间公开比价"的产品形态 | ❌ 多家竞价、报价排行榜、价格擂台 |
| 3 | **你做生意我帮忙**：平台只在用户主动求助时介入，且优先撮合"互补关系"而非"竞争关系" | ❌ 平台主动推荐"更便宜的卖家给你的客户" |

### 2.3 重新定位的产品关系

```
原设计（错）：                          新设计（对）：

  钢贸商A ─┐                            钢贸商A ─→ [私域工具+我的资源池]
           ├─→ [公开资源池]                          ↓
  钢贸商B ─┤    ↓                              [按需调货时才匹配]
           │  围观+比价                              ↓
  钢贸商C ─┤    ↓                            互补型同行（非竞争）
           ├─→ 杀价撮合                              ↓
  钢贸商D ─┘    ↓                              一对一私下沟通
                                                   ↓
              全员毛利下降                  双方都赚钱（互补型生意）

【输家：所有钢贸商】                     【赢家：每个参与的钢贸商】
```

## 三、新业务模型：四层结构（从私到公，按用户意愿渐进）

### 3.1 总体结构

```
                      公（平台主动介入度）
                          ↑
    ┌────────────────────────────────────────┐
    │  L4: 钢厂集采联盟 (我牵头，钢厂分润)     │  ← 平台 100% 主导
    │      赋能内容，不公开成员价格           │
    ├────────────────────────────────────────┤
    │  L3: 互补型撮合 (按场景定向匹配)        │  ← 平台帮你找你触不到的人
    │      钢厂剩料 / 跨区域 / 异常品种       │
    ├────────────────────────────────────────┤
    │  L2: 熟人圈调货 (用户自建关系网)        │  ← 用户主导，平台仅工具化
    │      你的私人调货圈，平台不可见关系     │
    ├────────────────────────────────────────┤
    │  L1: 我的私域库存管理 (每个客户独立)    │  ← 100% 私有，平台不可见
    │      库存可视、价格、客户、员工        │
    └────────────────────────────────────────┘
                          ↓
                    私（用户绝对主权）
```

**核心思想**：用户从 L1 开始，**自愿**逐层向上走。没人逼他公开，每往上一层，他获得的"额外价值"都明显大于"放弃的隐私"。

---

### 3.2 L1 — 我的私域库存管理（绝对私有，零暴露）

**这一层是基础**，必须先做好，建立信任。

| 维度 | 说明 |
|---|---|
| **谁能看** | 仅本企业员工（按角色权限） |
| **平台是否能看** | 否（数据加密存储；技术上做"端到端"隔离的演示） |
| **核心价值** | 多仓库存可视化、价格管理、客户档案、员工协同 |
| **与原 ERP 关系** | 这就是 ERP 的延伸，不需要新做 |

**关键功能**：

- 所有库存默认 "**私有**" 标签；
- 价格、客户、出货历史**全部本地+加密云**存储；
- 提供 **"绝对隐私模式"开关**：用户可以一键关闭"任何外部数据贡献"，平台不会因此减少他在 L1 的功能；
- 在产品中**反复明示**"我们看不到你的库存价格"——把信任写进 UI 文案。

**业务目的**：消除老板对"上系统就被监控"的恐惧。这是后续所有上层服务的前提。

---

### 3.3 L2 — 熟人圈调货（用户自建关系网，平台是工具）

**这一层不是平台撮合，是把钢贸商的"老调货关系"工具化、数字化**。

#### 真实业务场景（贴近行业现实）

> 王老板做钢贸 8 年，固定的调货圈子有 12 家同行：
> - 3 家是同区域可以互调的"互助伙伴"（互相补货）
> - 4 家是其他区域可以远调的"区域伙伴"
> - 3 家是品种互补的"品种伙伴"（你做螺纹我做板材，互相帮客户找货）
> - 2 家是钢厂代理"上游伙伴"（你帮我消化代理任务）
> 
> 这 12 家是王老板**多年攒下的私产**，他不愿意让其他钢贸商知道他在跟谁玩。

#### 平台怎么做（关键设计）

| 功能 | 说明 |
|---|---|
| **私有调货圈** | 用户自己建一个圈子，邀请已经认识的同行加入；平台**不主动推荐**任何成员 |
| **圈内库存共享（可控）** | 用户可对**特定圈子**开放部分库存（"对张总开放 Φ16 的库存，对李总不开放"），颗粒度到"对谁开放什么"|
| **一对一私聊调货** | 圈内只能 1v1 询价，**绝不允许群发竞价** |
| **价格不上墙** | 报价仅出现在两人对话中，平台不展示、不留存可索引数据 |
| **我帮你跟车** | 调货成交后，平台提供电子合同、物流跟踪、到货签收等"事务性服务" |
| **互助记账** | 双方互调时常发生"我先发你 8 吨 Φ16，你先发我 5 吨 Φ20"，平台帮记账双方累计往来 |

#### 与"找钢网模式"的本质区别

| 维度 | 找钢网模式 | 熟人圈模式 |
|---|---|---|
| 资源池 | 公开 | 仅圈内可见 |
| 比价 | 多家竞价 | 1v1 谈判 |
| 平台角色 | 撮合裁判 | 工具+服务 |
| 价格透明度 | 全平台透明 | 仅交易双方知 |
| 同行关系 | 竞争 | 协作 |
| 对毛利影响 | 击穿 | 维持/提升 |

#### 商业模式（这一层平台几乎不直接收钱）

- **不收撮合佣金**——一旦收佣金就有动力推动撮合，破坏熟人关系；
- **靠"事务性服务"赚钱**：电子合同 5 元/份、物流派单分润 5–10%、保险分销分润；
- **靠"互助记账+对账"赚钱**：高频用户买"专业版" 999/年；
- **靠数据沉淀间接价值**：调货数据沉淀进 L1 私域 + 征信平台（脱敏后）。

---

### 3.4 L3 — 互补型撮合（平台只匹配"非竞争"关系）

**这一层是平台主动撮合，但严格限定为"互补不冲突"的场景**。

#### 设计原则

只在以下三种情况下，平台才会做主动匹配：

| 场景 | 为什么"非竞争" |
|---|---|
| **场景 A：钢厂剩料/边角料处置** | 这是钢厂处置非主流库存，本来就不是钢贸商的常规生意，撮合不抢任何人客户 |
| **场景 B：跨区域大缺口** | 比如成都缺 200 吨 Φ20，本地全部钢贸都没货，从南京/上海调，平台可以匹配 — 跨区域不算抢同行 |
| **场景 C：异常品种 / 急单** | 客户要一个非常稀有规格（比如 Φ57×2.0 焊管+特殊牌号），本地 5 家同行都没有，平台才介入 |

> **核心判定逻辑**：**只要本地同行能满足，平台一律不撮合**。
> 平台的算法首先做"本地同行优先"判断，确认无人能满足后才发起跨圈匹配。

#### 怎么做（关键设计）

```
[BUYER 在 L1/L2 找货]
    └─ 先在自己的"熟人圈"问 (L2)
        ├─ 圈内有货 → 直接成交，平台不介入价格
        └─ 圈内没货 → 用户主动点"扩大查找"
                ↓
        平台进入 L3 撮合
                ↓
        判断这是不是"互补型场景"（A/B/C）
                ↓
                是 → 定向推送给"非本地+非竞争"的卖家
                ↓
                匹配成功 → 一对一沟通（不公开价格）
```

#### 与原"撮合"的本质区别

- **不广播询价**：不像找钢网那样把询价发给所有人比价；
- **定向匹配 1–3 家**：平台只推 1–3 家卖家，且他们与买家**不构成区域竞争**；
- **价格依然不上墙**：买卖双方私聊；
- **平台收"信息中介费 + 物流分润"**：不收"竞价撮合佣金"。

#### 商业模式

- **场景 A 钢厂剩料**：与钢厂分销中心合作，平台收钢厂 1–2% 信息分销费；
- **场景 B 跨区域**：买方付"跨区调货服务费" 1000–3000 元/单（含物流安排）；
- **场景 C 异常品种**：买方付"特种钢找货服务费" 500–2000 元/单。

**注意**：这些钱**都不是从钢贸商之间的差价里抽**，而是为"额外服务"付费。钢贸商感受是"花钱买省心"，不是"被平台割韭菜"。

---

### 3.5 L4 — 钢厂集采联盟（平台牵头，所有钢贸商一起省钱）

**这一层是真正的"加速器"——把全行业钢贸商的力量聚合起来，向钢厂团购拿更好价格**。

#### 真实业务场景

> 沙钢华东月度采购协议：
> - 单家钢贸商月提 500 吨：价格 P，无返点
> - 单家月提 5000 吨：价格 P-30，返点 10/吨
> - 单家月提 5 万吨：价格 P-50，返点 30/吨
>
> 实际情况：你的 2000 家钢贸商客户里，单家月提 5000 吨的不到 100 家，月提 5 万吨的几乎没有。
>
> **如果平台把 1000 家钢贸商对沙钢的需求聚合起来，月提 50 万吨，可以拿到 P-80 + 返点 50 的超级条件**——每吨节省 80–100 元，**每家钢贸商一吨多赚 30–50 元，平台抽 10–20 元**。

#### 怎么做（关键设计）

| 功能 | 说明 |
|---|---|
| **集采联盟会员制** | 钢贸商免费加入，但需提交"月度采购计划意向" |
| **平台与钢厂谈判** | 平台代表全体会员，每月与 5–10 家主流钢厂谈月度协议 |
| **联盟价不公开** | 联盟价仅会员可见，且**只显示自家可买的价格**，不显示其他会员的价格 / 数量 / 客户 |
| **按需提货 + 灵活分配** | 会员可以按月、按品种动态调整提货量 |
| **金融配套** | 平台联合银行/保理，给联盟会员提供"集采专项授信"，账期更长 |
| **不强制履行** | 会员可以不提货，但平台会统计履约率作为下次谈判筹码 |

#### 这件事为什么钢贸商一定会用？

> "我自己谈不下来的好价格，加入联盟后能拿到。每吨多赚 30 元，一个月多赚几万到几十万。我跟同行没有任何冲突——大家都从中受益。"

这不是"撮合"，是"**集体议价**"——所有钢贸商都是**赢家**，没有输家。

#### 与"撮合"的本质区别

| 维度 | 撮合（原设计） | 集采（新设计） |
|---|---|---|
| 谁是对手方 | 同行 | 钢厂（共同的上游） |
| 价格变动方向 | 同行间竞价（互相杀价） | 集体议价（共同压上游） |
| 平台收益来源 | 抽同行差价 | 抽钢厂返点 + 服务费 |
| 钢贸商情绪 | 被剥夺（毛利被压） | 被赋能（成本下降） |
| 行业关系 | 同行变对手 | 同行变盟友 |

#### 商业模式（这一层是平台**真正的核心收入**）

- **钢厂返点分成**：钢厂给联盟的返点，平台分 30–50%；
- **联盟会员费**：基础免费、企业版 1–3 万/年（享受优先提货、专属谈判、金融配套）；
- **金融配套分润**：与银行/保理合作，集采订单融资，平台分润；
- **物流配套分润**：联盟成员物流统一调度（不强制），平台分润。

**保守预估**：M12 末，10 家钢厂集采联盟，月聚合采购 30 万吨，钢厂返点 40 元/吨，平台分 30%，**月收入 360 万**——**远超过原"资源圈撮合"模型的预期**。

## 四、用 4 层结构重写"飞轮"

### 4.1 新的飞轮设计

```
                  【ERP 客户（已有 2000 家）】
                              ↓
                   【L1: 我的私域库存管理】
                   （绝对隐私，建立信任）
                              ↓
                   【对账单/合同/磅单工具】
                   （病毒拉新进来的新用户也先进 L1）
                              ↓
            ┌─────────────────┴─────────────────┐
            ↓                                   ↓
  【征信平台（用户自愿贡献）】          【L2: 熟人圈调货】
  数据网络效应                          私域工具化
            ↓                                   ↓
            └─────────────────┬─────────────────┘
                              ↓
                   【L3: 互补型撮合】
                   仅在"非竞争"场景介入
                              ↓
                   【L4: 钢厂集采联盟】
                   平台牵头集体议价
                   ↓
            真正的飞轮变现层
            （钢厂分润+金融分润+物流分润+服务费）
```

### 4.2 与原飞轮对比

| 维度 | 原飞轮（问题版本） | 新飞轮（修正版本） |
|---|---|---|
| L1 私域 | 缺失 | 必有，且明确强调隐私 |
| L2 熟人圈 | 没有，全员公开 | 用户自建私圈 |
| L3 撮合 | 公开比价 | 仅"非竞争"场景定向匹配 |
| L4 集采 | 一笔带过 | 升级为核心变现引擎 |
| 平台对钢贸商 | 对立面（撮合裁判） | 加速器（私域增强 + 集体议价） |
| 同行关系 | 竞争 | 协作 |
| 收入来源 | 抽同行差价 | 抽钢厂返点 + 服务费 + 金融分润 |

## 五、关键产品决策（必须坚守的红线）

### 5.1 永远不做的事

1. **永远不做公开询价大厅**——所有询价必须在私域或定向匹配中发生。
2. **永远不做"价格排行榜""卖家排行榜"**——不能让钢贸商在公开榜单上被压价。
3. **永远不让平台主动发"找货推送"给同区域同行**——避免抢客户感。
4. **永远不做"客户找钢贸商"的反向通道**——不能让钢贸商的客户在平台上找别的钢贸商。
5. **永远不做自营贸易**——不与客户竞争（这是找钢网最大的失败教训之一）。

### 5.2 必须坚守的事

1. **隐私写进 UI**：每个涉及"对外可见"的开关，默认关闭，且每次打开要二次确认。
2. **数据贡献完全自愿**：哪怕影响征信平台数据量，也不能强制。
3. **价格不可索引**：所有报价数据**绝不进入征信、不进入指数、不被任何第三方触达**。
4. **匹配算法可解释**：平台为什么推这家给你？算法解释清楚（地理远近 / 是否常合作 / 是否互补品种），让用户安心。
5. **争议处理倾向用户**：撮合或集采出问题，平台优先保护钢贸商利益，承担兜底责任。

### 6.5 合规与风控修订（新增条款）

- **反垄断风险**：集采联盟可能涉及"横向价格协议"嫌疑——必须由法务设计架构（建议平台是议价代理而非协议主体），避免触碰反垄断红线；
- **防泄密机制**：联盟成员的采购意向、提货量、价格，**严格隔离不互相可见**；
- **争议解决**：跨区域/集采订单由平台担保，承担兜底；
- **退出机制**：会员可随时退出联盟，平台不留存其历史数据可被同业访问。

## 八、对外沟通话术（如何把这个新模式讲给钢贸商）

### 8.1 给钢贸商老板的一句话

> "我们不做找钢网那种'把你库存挂出去让同行压你价'的事。我们只做三件事：
>
> 1. 帮你把自家生意管得更好（私域工具）；
> 2. 帮你和你的老调货圈协作得更顺（熟人圈工具化）；
> 3. 帮你和其他钢贸商一起向钢厂集体议价，共同多赚（集采联盟）。
>
> **平台只赚钢厂的钱、银行的钱、物流的钱——绝不赚你的差价。**"

### 8.2 给行业协会/媒体的一句话

> "中国钢贸过去 10 年最大的伤害，是软件平台的'透明化'让全行业毛利击穿。我们不重蹈覆辙。我们做的是'**集体协作型产业互联网**'——让 2000 家、20000 家钢贸商联合起来，用集体力量把上游议价权拿回来。这是行业自救。"

### 8.3 给投资人的一句话

> "我们规避了找钢网模式的根本性陷阱：不做公开撮合，不与客户竞争。我们的飞轮是'**私域工具 → 熟人圈协作 → 集采联盟**'，每一层都让客户**赚得更多**而不是赚得更少。这是为什么我们能在客户基础上做生意，而找钢网必须最终自营。"
